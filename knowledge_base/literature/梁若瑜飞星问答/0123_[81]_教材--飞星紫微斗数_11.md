# [81] 教材--飞星紫微斗数

防霸气，冲动行事。
化权的逻辑推理：
•   当A宫化权入B宫时，在性格的表现上，我们可以用一句话来推理：我的A宫积极於B宫，而欲掌控B宫。
•   当A宫化权入B宫时，在人事物上对我而言，我们可以用一句话来推理：我的A宫成就於我的B宫，而使我的B宫壮盛。
化权无法单独转忌，必须藉由化禄的带领，才可以因为化禄是机缘，在机缘的带领转忌到下一宫。此时禄权的交会，我们称为禄权交拱。
禄是机缘、舞台，嫩叶新枝，充满希望，却是脆弱的；权是能力、能量、力量，犹如保护的措施，让禄得以顺利的发展，扎扎实实的呈现出华丽的结果。有了能力要有舞台，有了机会要有能力才能发展，因此禄喜权护，权喜禄缘，交织出华丽而扎实的结果。
化忌也可以带权，权忌争战，让整件事呈现激化的状态，其破坏力被强化了，导致事态更为严重。
命宫坐生年权：我的A宫积极於B宫，而欲掌控B宫。
1.     我的个性天生主观，有主见，有自信，有能力。
2.     主观之人，不容易虚心受教，容易自以为是，或自恃甚高。
3.     个性刚强，容易任性，加忌，则刚愎自用。
命宫自化权出：
1.     我在不知不觉中过度展现我的自信、能力、主见，且不分场合，我容易有虎头蛇尾的现象，也容易是纸老虎的现象。容易自以为是。容易在不知不觉中爱膨风。
2.     权出有变动快速之意，自化权出，又是不够用心，因此容易没有定见，见异思迁，所以事情容易反反覆覆。
命宫化权入兄弟：我积极於兄弟宫，而欲掌控兄弟宫。
1.     我在兄弟间占权，所以我容易是长子格。
2.     我容易积极地开创事业。我的自信、主见、能力展现在事业成就上，因此我容易有「见地」、「抱负」、「活力」，也具『企图』、『开创』、『积极』。敢策划、投资。
3.     我的自信、主见、能力展现在事业成就上，因此我容易具『胆识』与『决断』、『领导』〈权冲交友〉〈防霸气〉。
4.     我的自信、主见、能力展现在事业成就上，因此我容易开源、兼职、创业。敢赚敢花，理财有方。
5.     容易重『物质生活』。
命宫化权入夫妻：我积极於夫妻，而欲掌控夫妻。
1.     我在夫妻间占权。对婚姻或感情的支配欲望高，逢忌容易有纷争。
2.     很容易获致事业成就〈权照事业〉。
3.     拥专业、专技尤能开创。
命宫化权入子女：我积极於子女，而欲掌控子女。
1.     我积极的栽培、管束子女〈加福德、疾厄「忌」，「严苛霸道」〉。
2.     我积极的参与或邀约合伙事业，容易在合伙事业掌权。
3.     子女为田宅的迁移，我的能力容易在外展现，所以适合往外发展。
4.     容易「房事过度」〈桃花星〉。〈加忌尤显〉。
命宫化权入财帛：我积极於财帛，而欲掌控财帛。
1.     我积极的想赚大钱，因此具有积极的企图心，与开创、应变的能力。
2.     我掌控钱财，加上企图心强，所以敢赚敢花、活动力强。喜欢做利润高或大笔的收入〈权〉的生意。
3.     我掌控赚钱之道，加上企图心强，适合专业技能的发展，容易『升迁：高薪或高职位』、『创业』，也容易「兼职」、「副业」。
4.     汲营三方坐权，均适合市场的『开发』、『领导』与『销售』。
注：『财帛』为现金位。得「禄」、「权」者，都适合市场的『开发』、『销售』等直接『创造利润』的作为。当然也适合现金生意。
命宫化权入疾厄：我积极於疾厄，而欲掌控疾厄。
1.     我积极运作我的身体，所以我『好动』、「积极」、『耐力』、「运动」。
2.     我的『抗压性』高、蛮皮、「拖病延医」。
3.     权有大的意思，疾厄是肢体语言、动作、习性。所以在个性的表现上，比较不矫饰、粗线条。
4.     好运动，所以体型容易比较『结实』、健美，「小病少」。防「运动伤害」，『瘀、内伤』〈「权、忌」同宫尤显〉。
5.     适合「运动量大」的工作，也重「物质生活」。
命宫化权入迁移：【权出】我积极於迁移，而欲掌控迁移。
1.     我的自信、主见、能力展现在外，所以我的性格是有『活力』、『能干』、『果断』、『智慧』、『胆识』、『权变』、『意志力』。
2.     我的自信、主见、能力展现在外，所以我的观察力敏锐，应变能力佳、善谋略〈懂得权变〉，可以『领导统驭』、『开创拓展』。
3.     我的自信、主见、能力展现在外，所以我的决断力强，做事明快，不喜欢拖泥带水。
4.     我的自信、主见、能力展现在外，我如有专业技能更好。
5.     格局不佳，『独断』、『霸气』、『自负』，容易结怨。喜会「禄」，而得兼容并蓄，处世圆融。
命宫化权入交友：我积极於交友，而欲掌控交友。
1.     我会积极主动参与且想要掌控人际上的事务，所以我的个性比较「鸡婆」（热心）、「爱现」、「替人出头」。或喜欢『支配』、「成就」他人。利於学术的专业涵养。或利於公职的服务人群。
2.     我会积极主动参与且想要掌控人际上的事务，所以我的个性比较善於『人事运作』，可以成就别人。利於『幕僚』工作〈能成就上司、老板〉。
3.     格局差，防『自以为是』，「不纳忠言」、「曲高和寡」；或防『金玉其外』、虚有其表。
4.     利於「竞争」、「考试」、「公职」。交友为竞争位、考试运位。
命宫化权入事业：我积极於事业，而欲掌控事业。
1.     我积极掌控运作我的事业，所以在事业的表现上往往具有强烈的企图心，有「见识」、『积极』、『开创』、「自信」、「活力」。『谋略』、『应变』能力。
2.     我积极掌控运作我的事业，所以在事业的表现上往往具有强烈的企图心，工作能力好，容易升迁、创业。
3.     我积极掌控运作我的事业，所以在事业的表现上往往具有强烈的企图心，适合开发、企划、专技、专业的『领导』、执行。
4.     「权」喜『禄』会，则更具「顺手」与「发挥」的空间；会『科』则兼俱「果敢」与「细腻」；会『忌』则为拼命三郎、老板兼伙计。
5.     对待配偶的态度比较强势〈权冲夫妻〉。
