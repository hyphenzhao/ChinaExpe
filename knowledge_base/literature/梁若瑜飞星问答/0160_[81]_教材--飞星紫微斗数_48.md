# [81] 教材--飞星紫微斗数

禄出：
1.       兄弟宫自化禄出，表示兄弟有禄，只是没有原则的禄出，浮夸松散的现象，所以看似兄弟间感情蛮好的，却容易不团结。
2.       事业成就为自化禄出，一有禄，所以事业、金钱有顺遂的一面，又没有原则的禄出，浮夸自己的事业成就与经济，因此是好，但没有看到的那么好。松散的理财方式，当然不佳。
3.       事业成就自化禄出，禄出有变动快速之意，所以适合现金生意，或以销售、业务、服务业等短期见利的工作，但必须认真於管理。自化禄出，代表不够用心。
4.       逢他宫「忌」入，则我『库遭劫』〈同星曜「禄忌」成『双忌』〉。加倍之损，重复损失。
5.                     健康有良好的一面，但不够扎实。
事对人：
兄弟论事以事业成就为主，与身体有关的论体质。
我的事业成就庇荫我的六亲、友人。
事对事：
兄弟论事以事业成就为主，与身体有关的论体质。
我的事业成就的表现。
生年禄入兄弟宫：
要转忌入人的宫位，才能看到对那些人有帮助。
生年禄入兄弟宫：
1.         兄弟为事业的疾厄，论事业规模；兄弟为财帛田宅，论经济实力，为存款位。两式合称事业成就位。我的事业与经济常好，若失败容易东山再起。或利於升迁、创业(命宫同星曜化权来会更明显)。
2.         兄弟为疾厄的事业，论身体气数位，为我的体质位。我的体质好，少病痛的困扰。
兄弟宫化禄入夫妻宫：
1.         我的事业成就与经济好带给配偶快乐。荫配偶。婚后事也会再往上推升。
2.         我的体质有很好的一面，带给配偶快乐，最好是廉贞、或贪狼禄，就可以描述为性功能强，带给配偶快乐。
3.         我的事业成就带给异性快乐，可以从事以异性客户为主的行业。
4.         我的经济好带给配偶快乐，配偶手头很宽裕。
兄弟宫化禄入夫妻宫：
1.         我的事业成就、经济好照事业宫，让事业顺遂。
2.         长久的体质状况好（兄弟―身体运、夫妻―疾厄的田宅）。
3.         事业成就与夫妻婚姻有关，可以从事相关事业。如婚友社、跨国婚姻仲介。
兄弟宫化禄入子女宫：
1.         我给小孩「零用钱」充裕。
2.         适合做小孩有关的生意，或宠物相关的生意。
兄弟宫化禄入子女宫：库位禄出
1.         我的经济好、花用多、少有理财观念〈库位禄出〉。
2.         健康好，性生活美满。尤其是贪狼或廉贞禄。
3.         有利於合伙，收入好。
兄弟宫化禄入财帛宫：
1.         小库位挹注我的现金，所以我的经济宽裕，手头方便。缺点是少用心理财而多花用。
2.         事业成就禄入现金缘的位置，所以适合周转变现快，现金生意。收入好。
3.         物质生活好。
兄弟宫化禄入迁移宫：禄出
1.         事业成就禄出於社会。所以我的事业容易有成、事业顺遂、信誉好，社会地位好，可以建立品牌。
2.         经济实力禄出，信用良好，周转会很方便，善理财者，可以钱滚钱。
3.         要学会善用广告、文宣、媒体容易有利於发展业务、行销。建立品牌行销。
4.         事业成就名声显於外，有好的口碑，所以适合业务、销售，也利於创业、升迁。
5.         体质好，健康。
兄弟宫化禄入交友宫：
1.         事业成就化禄入交友，做生意要往人堆里钻，生意上善攀机缘，多往来交易。
2.         适合人潮多的生意，也适合流行、时尚的事业。事业成就禄出。
3.         经营自己的品牌。
兄弟宫化禄入交友宫：
1.         库位禄出，所以经济好看的到，大笔花用多少了理财的用心。
2.         库位禄出，大笔花用，但信用好，所以适合大批发、大卖场、产地直销的生意。
3.         适合流行、时尚的事业。事业成就禄出。
4.         经营自己的品牌。
兄弟宫化禄入事业宫：
1.         我的事业成就让我事业顺遂，我的资金充足（口袋较深）、周转顺畅，可以循环营利（钱滚钱）。
2.         我的收入好，利於升迁、创业。
3.         兄弟工作顺心，且兄弟荫我事业，适合与兄弟合伙佳。
兄弟宫化禄入田宅宫：
我的事业成就好且稳定成长，带给家人物质生活上很宽裕很好。
兄弟宫化禄入田宅宫：
1.         我的事业成就好，带给家庭、财产兴旺。福入收藏宫，稳定发展，收入好，经济丰足。
2.         事业越做越顺。产业、财富蒸蒸日上。可以多置产。
3.         我容易是长子格。
4.         适合经营居家用品的行业。比如说家具、家饰、五金、、、、
兄弟宫化禄入父母宫：禄出
1.         我的事业成就好带给父母宽心愉快。
2.         我给父母的孝养金丰厚。让父母物质生活好。
3.         事业成就带给长辈快乐，适合经营银发族的相关事业。
兄弟宫化禄入父母宫：禄出
1.        兄弟有和睦的一面，有福德或迁移的串连，才是真和睦，否则可能只是表面上的和睦而已。
2.        事业成就位禄出，所以我经济宽裕、信用好。
3.        体质好，神清气爽〈父母―形於色〉。
