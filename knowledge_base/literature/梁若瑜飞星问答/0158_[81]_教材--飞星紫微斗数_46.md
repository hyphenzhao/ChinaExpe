事业宫自化忌出：
1.         自化忌出，除了没有原则的（不知不觉中，不经意当中，且不分场合）出而不藏（显像出来）、消散（过了就算了）之外，还有变动快速之意、不够用心、忘性。
2.         适合任公职、或在大企业上班，比较安稳。
3.         做生意适合速战速决，无囤货、不压本，通路快的作法。
4.         适合以技术或服务为主得行业，如小本生意、仲介、技术、顾问、会计、代书等。或生活杂货、日用品、消耗品等生活所需用品（忌出为消散，重复购买）。非常不适合『生产事业』。
5.         汲营三方自化者，做生意很难做到一成不变的产品就能永续的经营，所以比较不适合「生产行业」。
事业化忌入（人）的宫位
事业化忌入（事）的宫位
事业宫化忌入兄弟宫：
1.         事业化忌入兄弟，对我兄弟而言，我的工作或事业对他没有帮助。
2.         在工作上的个性较守成内敛，对朋友不多情，少社交〈冲交友〉。
事业宫化忌入兄弟宫：
1.         命三方忌入收藏三方，为安定守成，个性内敛，对朋友不多情，少社交活动。（冲交友三方）
2.         兄弟宫为收藏三方，为安定位、守成位。所以事业化忌入兄弟代表我工作或对事业上的态度是寻求安稳安定的、个性比较保守、守成持重。
3.         一忌入六，兄弟为事业的共宗六位，所以有辛苦累积打拼的个性。容易向公务员、或大型企业的上班族，上班安定到退休。
4.         一忌入六，事业化忌入事业的疾厄宫，所以容易事必躬亲，亲力亲为，老板兼伙计。
5.         也适合做现金生意，亲力亲为的辛苦之得。
事业宫化忌入夫妻：事业忌出
1.         事业化忌入夫妻，我的工作或事业会让配偶担心。或需要配偶的帮忙。或成为配偶的负担。
2.         如果我要创业时，可能需要配偶帮忙，一起打拼，胼手胝足。
3.         特殊情况：如果是廉贞或贪狼化忌，我可能沾染到烂桃花，会破坏婚姻。
事业宫化忌入夫妻：事业忌出
1.         我的工作或事业忌出，忌出有变动快速之意，所以在工作上的耐性不足，容易变动。运限不好时，尽量寻求上班安定。
2.         忌出也是出而不藏，表示工作的样子不好看表现出来，或不顺遂表现出来。所以工作有辛苦或样子不讨喜或际遇不好等现象。
3.         事业忌出，忌属水，忌出流动快速，适合现金买卖，变化快速的行业。不适合投资大回收慢的行业，如生产事业。
4.         如果能习得一技之长，适合提供技术服务、或顾问业、或仲介、或买卖、或代书等服务业，不须要囤货、不压本金的行业。忌出，因为是变动快速，所以适合以不同对象为服务对象为佳。
事业宫化忌入子女宫：
1.     我的工作或事业需要小孩帮忙，或成为小孩的负担，容易工作全家忙。
2.     特殊情况：如果是廉贞或贪狼化忌，我可能沾染到烂桃花。
事业宫化忌入子女宫：冲田宅
1.     我的工作或事业造成合伙事业的阻碍或发展。
2.     事业化忌入交友三方，冲田宅三方（收藏、安定），主人生变动多，起伏比较大。重义轻利。
3.     诶的工作或事业容易不顺遂、不稳定，人生多起伏。难守成。
4.     适合任公职、或在大企业上班，比较安稳。
5.     事业化忌入子女冲田宅，适合店、家分开。
事业宫化忌入财帛宫：
1.         工作或事业带给我的收入不多，现金缘不佳。
2.         上班工作适合固定薪资的工作，公职或大企业上班好。
3.         做生意适合利润薄的小生意。
4.         不可从事大投资回收慢的行业，不可囤货、压本。
5.         最宜上班族的『固定薪水』。
事业宫化忌入迁移宫：事业忌出
1.         工作上不善攀缘，手腕较差。
2.         憨憨的做，没有人帮忙。工作上的个性拙朴憨直，不讨好。
事业宫化忌入迁移宫：事业忌出
1.         迁移为智慧宫位，为处世应对的的能力，忌为歛藏。忌坐迁移为笨拙显於外。
2.         工作或事业上的表现拙朴憨厚、不善攀缘、手腕不好，不讨好。
3.         工作或事业上往往际遇不好没有贵人相助、或没有社会资源的协助、或天不从人愿，所以比较不适合做生意、或投机不利。
4.         比较不适合投资创业，容易接单不顺、或工作停摆。（忌入迁移宫为持续忌出）
5.         适合以提供技术或以服务为主的行业，如仲介、顾问、技术、会计、代书等服务业〈不需囤货、压本〉。
6.         适合任公职、或在大企业上班，比较安稳。
事业宫化忌入交友宫：
1.         重义轻利。（命、财、事业三方忌入交友三方，都有重义的性格，冲财库三方，为财库忌出，所以轻利）。
2.         工作或事业带给同事困扰，渐渐地没有工作伙伴，需要独立作业完成。
3.         工作或事业带给朋友困扰，不利於合伙，我容易拖垮朋友，因为我重义轻利，导致经营不得要领。
事业宫化忌入交友宫：
1.         重义轻利的个性，最好不要当老板，容易经营不善，事倍功半（冲兄弟事业成就位、收藏安定位），人生也会有比较多的起伏，守成不易。
2.         上班族比较好，或做小生意。
3.         事业化忌入交友三方，冲田宅三方（收藏、安定），主人生变动多，起伏比较大。重义轻利。
事业宫化忌入田宅宫：
1.         我的工作或事业成为家人的负担，或需要家人的帮忙，如果我做生意，家人需要帮忙〈忌，辛苦累积〉。
2.         工作全家忙。
