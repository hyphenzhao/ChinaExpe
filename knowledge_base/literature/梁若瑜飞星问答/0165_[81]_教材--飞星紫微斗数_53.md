# [81] 教材--飞星紫微斗数

。【同象非必同果】
但是如果是心脏病，一定跟太阳化忌有关。【同果必同象】
飞星紫微斗数在解释上有三个层面：
一.对我而言是什么事。
二.对他人而言是什么事(他人指的是人的宫位或借盘论六亲时的宫位)。
三.我和他之间的对待关系。
单独某两个宫位互化的解释，为我有一面的个性特质，人生是很多面的，遇到不同的人事物，都有不同的表现方式。
忌的推理：歛藏、执著、付出。
命宫化忌入B宫，用一句话来推理解释：我在乎B宫的人事物，而我愿意为B宫付出。命宫是我的心、精神、思考，化忌表示我会专注在哪里。
生年忌为先天之功课，是我的责任、义务，而命宫化忌为后天导运之思维专注点，产生与诸多人事物的对待关系。
一忌为劳，红尘当然是尔。每个人在世上，或多或少都必须付出的。
二忌为病，当相关宫位串连呈现2忌，表示事情会发展到紧缩，或出现病灶，但还不至於影响成败。若以病痛方面来解释，犹如人之酸痛、疲累、无神、感冒等，看看门诊多休息就没事了。若以金钱来论，已经出现抓筋见肘，经济趋紧的现象，但不至於空。
三忌为破，当相关宫位串连呈现3忌，表示事情会发展到出现实际的病症或败象。如人之生病需住院治疗了。如人金钱上已经出现空虚之象。
四忌为败。当相关宫位串连呈现4忌，表示事情会发展到非常严重的地步。如人生病进加护病房命悬一线了。如人财务上已经大败可能破产跑路或负债。
生年忌入夫妻：（对人）
1.         夫妻的命宫坐生年忌。
2.         欠夫妻债。夫妻是我的功课。我会执著於感情。
3.         欠感情债，我对感情容易投入执著。
生年忌入夫妻：（对事）
1.         欠婚姻债。纵使离婚也必经一番波折。
2.         执著於婚姻，冲事业，容易想先成家后立业。
3.         事业忌出，容易工作不稳定，所以适合上班安稳。若要做生意，适合做现金生意。
4.         夫妻为福分财，坐忌为收敛，忌赌、投机。婚后适合单纯的『小家庭』。
夫妻化忌入命宫：（人对人）冲迁移
1.         我夫妻的命宫化忌入命宫，视同夫妻的命宫坐生年忌。
2.         我的配偶固执不好沟通，容易处处干涉我、或配偶紧迫盯人，或配偶带给我诸多苦闷。
3.         配偶不是我真正喜欢的对象。或遇到错误的对象，造成我的苦难。
4.         或异性小人纠缠。容易遇到错误对象对我纠缠不已。
夫妻化忌入命宫：（事对我）冲迁移
1.         欠债的婚姻、或欠感情债，婚姻的是带给我诸多烦恼。
2.         婚后个性容易渐渐收敛而孤独（忌冲迁移）。
3.         婚姻或感情生活容易不能如愿，带给我苦恼。
4.         福德三方忌入命，天不从人愿。所以没有赌、或投机的命，没有不劳而获的条件。
夫妻忌入疾厄：（人对人）
1.         我夫妻的命宫化忌入入疾厄。
2.         我的配偶有一段时间喜欢黏著我、或像跟屁虫依样跟在我身边。谈恋爱时，容易形影不离。结婚后容易紧迫盯人。
3.         配偶或异性让我忙碌。
4.         异性纠缠。
夫妻忌入疾厄：（事对我）
1.         欠婚姻债，为婚姻而忙碌。或婚后更忙碌。
2.         婚姻生活比较没有情趣、或紧张、或刻板。
夫妻忌入福德：（人对人）
1.         夫妻的命宫化忌入福德。
2.         配偶让我烦恼，或为恶缘的感情。
3.         或异性小人纠缠。容易遇到错误对象对我纠缠不已。
夫妻忌入福德：（事对我）
1.         容易是恶缘的婚姻或恶缘的感情。欠婚姻债、感情债。
2.         婚姻或感情生活天不从人愿，带给我烦恼和苦痛。
3.         福德三方互忌，天不从人愿。所以没有赌、或投机的命，没有不劳而获的条件。
夫妻忌入兄弟：冲交友（人对人）
1.         我夫妻的命宫化忌入兄弟宫。
2.         我的配偶忌入兄弟，私心较重，容易与兄弟计较而生争执或困扰，婚后兄弟间的感情渐渐变淡了。婚后也不适合在家族事业共事。
3.         冲交友，婚后也容易朋友较少往来。
夫妻忌入兄弟：冲交友（人对事）
1.         我的配偶比较安静内敛，所以婚后与朋友的往来渐渐减少。
2.         我的配偶忙於工作，导致婚姻上的相处时间少、或少闺房之乐、或草率房事（冲交友，婚姻共宗六位）（兄弟也是夫妻的夫妻的田宅，论主卧室）。
3.         配偶干涉我的事业或经济。不适合共事。
夫妻忌入兄弟：冲交友（事对人）
我的婚事，兄弟帮忙操心、操办。
我的婚是比较得不到朋友的祝福。
夫妻忌入兄弟：冲交友（事对事）
1.         婚后我的事业成就下滑或收入下滑。
2.         婚姻生活渐趋冷淡，冲交友，婚姻共宗六位。交友论感情或婚姻的甜蜜度。婚姻倦怠症候群。
夫妻忌入子女：（人对人）
我夫妻的命宫化忌入子女。
我的配偶疼小孩。
夫妻忌入子女：（人对事）
我的配偶会干涉我的合伙事业。
不适合与异性合伙。
夫妻忌入子女：（事对人）
我的婚姻若有问题，则会造成小孩的困扰、或负担、或担心、或阴影。
夫妻忌入子女：（事对事）冲田宅
桃花星化忌，婚外情破坏家庭。
婚后适合小家庭。
夫妻忌入财帛：（人对事）
1.         我夫妻的命宫化忌入财帛。
2.         我的配偶干涉我用钱，或给我用钱不方便，或会计较我用钱。
3.         夫妻不适合共同经营事业，为钱伤神伤感情。
夫妻忌入财帛：（事对事）
1.         婚后我的收入减少，容易造成贫贱夫妻百事哀。
2.         夫妻化忌入夫妻的夫妻，相欠债的婚姻。婚姻对待关系不好，容易比较多争执或相处冷淡。或沟通欠佳，或相处越来越无趣。
3.         婚后要谨慎理财，避免为财伤
4.         福德三方忌入财帛，天不从人愿。所以没有赌、或投机的命，没有不劳而获的条件。
5.         很容易桃花破财、桃花债。
夫妻忌入迁移：（人对事）忌出
1.         我夫妻的命宫化忌入迁移。
2.         我的配偶耿直善良、心直
