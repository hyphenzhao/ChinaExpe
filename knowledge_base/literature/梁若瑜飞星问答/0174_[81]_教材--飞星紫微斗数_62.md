# [81] 教材--飞星紫微斗数

的命宫化禄入疾厄。
父母宫化禄入福德宫：
1.         父母与我是善缘的，相处融洽。容易有忘年之交。
2.         父母庇荫我，帮助我，带给我如意顺遂。
3.         老板或上司的缘好，有利於受提拔而升迁。
4.         读书学习是一件快乐的事。聪明容易领悟，心想事成。
5.         公家机关的缘好。利於公职，利於与公家机关打交道。
6.         父母是交友财，所以容易周转方便。贷款容易。
7.         父母是修养宫、涵养宫，禄入福德，修养涵养会水到渠成，心境上容易随缘自在，自我调适。
8.         交友三方化禄入命疾福，都有喜欢听好听的话，尤其是禄入福德。福德是享受位。
9.         父母的命宫化禄入福德。
父母宫化禄入兄弟宫：
1.         父母比较亲近我的兄弟，与我兄弟的感情比较好。
2.         兄弟为收藏三方，是我生活周遭的环境，所以我与叔叔伯伯往来较频繁。
3.         我与朋友或银行金钱常有往来，信用好，金钱调度方便。
4.         兄弟为事业成就位，所以有利於广告行销，可以加强广告行销，有利於销售业绩的提升。
5.         父母的命宫化禄入兄弟。
父母宫化禄入夫妻宫：
1.         父母祝福我的婚姻。或促成我的婚姻。
2.         父母对我的配偶很好。与我的配偶有缘。所以婚后可与父母同住。
3.         父母是文书宫，表示我的婚姻是明媒正娶的，名正言顺。
4.         父母的命宫化禄入夫妻。
父母宫化禄入子女宫：
1.         我的父母宠爱我的子女，表示祖孙关系好，含饴弄孙。
2.         父母为表达宫，表示我在教育小孩时用字遣辞得体，给小孩的观感是形象好，谦恭有礼。
3.         我的子女容易遇到好的师长。
4.         父母的命宫化禄入子女。
父母宫化禄入财帛宫：
1.         我的父母给我用钱方便，所以我小时候零用钱多。
2.         父母为交友财，我与朋友或银行常有金钱往来，信用良好，金钱调度方便。
3.         我的父母资助我钱财。
4.         我适合以银发族为客户对象的行业。
5.         适合从事现金生意、四方来财。金钱调度方便。
6.         父母的命宫化禄入财帛。
父母宫化禄入迁移宫：
1.         父母外缘好，开明识大体，容易在社会上有身分有地位，社会资源好庇荫我。
2.         我的老板或上司外缘好，开明识大体，容易在社会上有身分有地位，提拔我。
3.         我容易结交到的长辈，容易是外缘好，开明识大体，容易在社会上有身分有地位，或德高望重者。忘年之交。
4.         我的修养涵养好、为人有礼貌、在社会上形象好、亲和力好、表达得体。也善於自我调适。
5.         读书学习领悟力高，容易学历好、世故练达，能创造立足社会的好条件；容易高职、高薪。
6.         利於念书、升学、证照等考试。利於公职、升迁。也适合文化工作者、慈善事业。
7.         记性特佳，可以见多识广。
父母宫化禄入交友宫：
1.         我的父母开明与我的朋友可以打成一片。
2.         我有年长的朋友。
3.         交友为考试竞争位，父母化禄入交友，有利於考试竞争。
4.         我的修养、涵养、形象、表达带给朋友快乐，所以我容易喜欢说圆融好话。外表、形象在人际间蛮好的。
5.         父母的命宫化禄入交友。
父母宫化禄入事业宫：
1.         父母庇荫（帮助）我事业顺遂。容易获得长官、老板、上司的关心和提携，或父母长辈的帮忙。有利於升迁。
2.         事业宫为我的工作或事业，父母是政府机关，所以有利於考取证照、或公家机关任职、或有利於从事与公家机关相关业务。
3.         父母是读书学习位，在读书的过程是按部就班地像工作一样的读书，或者容易学以致用（所读的科目为将来执业的工作）。
4.         父母为文书宫，也适合文化工作者，或者文创业者（创意要有才华，所以最好是串连廉贞、贪狼才华星）。
5.         父母的命宫化禄入事业宫。
父母宫化禄入田宅宫：
1.         父母庇荫我帮助我的家庭、财产。帮助我置产，或者帮助我生活上之所需。
2.         父母带给我的家庭快乐，或亲近我的家庭。父母如果住在我家，父母开明，和乐同堂。
3.         父母亲近家族的人，父母比较热衷於家族间的往来，或宗族的长辈多往来。
4.         父母为交友财，我容易贷款置产。（田宅化禄入父母，容易全额置产，不用贷款）。
5.         父母为文书宫，化禄入田宅，表示家庭文风鼎盛，家族容易出有学问者。
6.         父母为夫妻的田宅，表示亲家、姻亲多往来。
父母宫自化禄出：
1.         自化禄出，为没有原则（不知不觉中、不经意当中、且不分场合）的表现出好的一面，有浮夸之意。且有变动快速之意。也有消散之意。因此对父母好的态度容易流於表面功夫。缘分稍嫌不足，父母可能必须自给自足。
2.         有善於表达、温和、亲和的一面，容易流於表面功夫，皮笑肉不笑，有口无心。
3.         容易读书、学习聪明有余而用心不足，未尽全力、不求甚解。

飞星紫微斗数在解释上有三个层面：
一.      对我而言是什么事。
二.      对他人而言是什么事(他人指的是人的宫位或借盘论六亲时的宫位)。
三.      我和他之间的对待关系。
单独某两个宫位互化的解释，为我有一面的个性特质，人生是很多面的，遇到不同的人事物，都有不同的表现方式。
