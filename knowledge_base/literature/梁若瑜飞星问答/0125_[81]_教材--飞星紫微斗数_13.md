事业权入财帛：我的事业宫成就於我的财帛宫，而使我的财帛宫壮盛。
1.     我的工作能力，或我的专业能力，展现在财帛宫，所以在赚钱的领域容易展现我的「主见」、「积极」，有『拓展』空间。可以『高单价』、『高利润』、『高收入』。
2.     我的工作能力，或我的专业能力，展现在财帛宫，所以适合『开发』、『领导』的工作。
3.     我的工作能力，或我的专业能力，展现在财帛宫，容易高薪、高职位，或业绩「分红薪水」。也容易『创业』、『升迁』。
4.     权喜禄会，则「机遇」更好、「拓展」的空间更大。
注：不论「财帛」禄入「事业」或「事业」禄入「财帛」皆指事业上的「现金缘好」，故宜从事『业务』与『销售』工作。财帛「权」入事业或事业「权」入财帛则适合於专业与专技的『领导』、『开创』工作。
事业权入疾厄：我的事业宫成就於我的疾厄宫，而使我的疾厄宫壮盛。
1.     我的工作能力，或我的专业能力，展现在疾厄宫，所以我的身体充满活力、干劲。
2.     工作的体力消耗比较大，活动量比较大。
3.     工作的抗压性比较强。
4.     工作上比较耐劳、耐操。
5.     工作上的个性表现比较主动、干脆。
6.     适合从事技术性粗活。
7.     格局好，收入高，敢赚敢花。
事业权入迁移：权出。我的事业宫成就於我的迁移宫，而使我的迁移宫壮盛。
1.     我的工作能力，或我的专业能力，展现在社会上，所以我的能力强，积极有活力，在社会活耀。
2.     最适合拥有『专业』、『专技』、『专利』，利於『开创』、『领导』
3.     事业权出，格局佳，容易营造「气势」、可以『建立品牌』。
4.     事业权出，利於『升迁』、『创业』。
事业权入交友：我的事业宫成就於我的交友宫，而使我的交友宫壮盛。
1.     我的工作能力，或我的专业能力，展现在人际交往上，所以帮助同事、成就老板(交友为父母的事业)，所以是好的幕僚格。
2.     在人际间比较活耀，容易爱现，成就他人。
3.     适合促销、「大卖」、「批发」，「口碑」与「信誉」的生意。
事业自化权：〈权出〉
1.     我的工作能力，或我的专业能力，自化权出，不知不觉的表现出来，不会看场面的表现出来，所以容易膨胀自己的工作能力和专业能力，自化表示不够用心，因此容易不得要领。自化为变化快速，因此不容易持久，也容易虎头蛇尾。
2.     做生意以『追求时尚』、『领先潮流』、『创新产品』的作法为佳。生意手法也应以「机动性」、「多元化」、『且战且走』为佳。
3.     适合於『专技』、『专业』的工作。不适合投资大、回收慢的生产事业。
事业权入田宅：我的事业宫成就於我的财帛宫，而使我的财帛宫壮盛。
1.     我的工作能力，或我的专业能力，展现在田宅上。所以我容易积极有活力，充满干劲。权入收藏宫，事业多稳定、拓展。
2.     利於『升迁』、『创业』。拥「专技、专业」尤佳。
3.     适合与田宅(田地家宅)有关的行业，如房地产、建筑业〈偏财星〉、五金、装潢、水电、家电、家具、家庭用品行业。
4.     可「高薪」、「高职」或业绩「分红薪水」。
事业权入福德：我的事业宫成就於我的福德宫，而使我的福德宫壮盛。
1.     我的工作能力，或我的专业能力，展现在福德。所以我容易积极有活力，充满干劲。不认输、好胜，所以企图心强烈。
2.     不认输，好胜，所以爱面子，讲场面、多『应酬』。容易「大手笔」的作为(权冲财帛，或财帛权出)。
3.     格局好，权照财帛，很会赚钱，事业越做越大。容易「大笔」收入。
4.     最好拥有专业技能，或特殊技能。
事业权入父母：我的事业宫成就於我的父母宫，而使我的父母宫壮盛。
1.     事业权出，我的工作能力，或我的专业能力，展现於外。所以我的能力强，积极有活力，在社会上活耀。
2.     权出，利於「专业性」、「专利性」工作。
3.     化权入父母、迁移，表达宫，利於「专业讲师」、「学有专精」等具「说服力」工作。
4.     权出，父母是形於表的宫位，所以利於『广告』、「促销」。
5.     父母是学习位，事业是工作，化权是积极，因此在读书的过程容易「在职进修」、「边做边学」。
以赚钱的角度来论：事业、财帛化权入财宫或性格宫，最好拥有专业技能，可以高薪、高职位。

09-2 兄弟化权入12宫
飞星紫微斗数在解释上有三个层面：
一.  对我而言是什么事。
二.  对他人而言是什么事(他人指的是人的宫位或借盘论六亲时的宫位)。
三.  我和他之间的对待关系。
单独某两个宫位互化的解释，为我有一面的个性特质，人生是很多面的，遇到不同的人事物，都有不同的表现方式。
化权的质性(归纳推理：壮盛、掌控、成就於)
权：在八卦衍生中四象的【老阳】，自然现象中为【夏天】，是属『火』旺之象，万物壮盛，充满力量。
具有以下特质：( 梁若瑜老师著作：十二宫六七二象 )
1.自信、主见、企图、抱负、积极、欲望。
2.领导、开创、拓展、突破、结实、壮大、权力、地位。
3.主观、能力、应变、果断、刚毅。
4.胆识、行动、运动、强硬、霸气、尖锐、争斗。
5.大的、新的、多的、好的。
推理解释为：
壮盛：用Power来形容也蛮贴切的。
掌控：性格上的表现(命宫、福德宫，具有思考能力。迁移宫是处世应对的能力)。
成就於：人事物，均可适用。
权是一种力量的表现，非因缘。
权的态度是积极的。
作为上：要圆融柔和、谦虚、防霸气，冲动行事。
