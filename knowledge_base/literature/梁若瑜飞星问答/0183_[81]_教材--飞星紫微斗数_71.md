第07堂  迁移四化入十二宫的推理解释
第三单元  迁移化科入12宫
飞星紫微斗数在解释上有三个层面：
一、  对我而言是什么事。
二、  对他人而言是什么事(他人指的是人的宫位或借盘论六亲时的宫位)。
三、  我和他之间的对待关系。
单独某两个宫位互化的解释，为我其中一面的个性特质，人生是很多面的，遇到不同的人事物，都有不同的表现方式。
化科的质性(归纳推理：文质、理智、缓和)
科：是八卦衍生四象中的【少阴】，为秋天，属『金』旺之象，万物见盛而制，充满肃杀之气。圣人依此自然法则，制定礼乐教化而产生文明。
具有以下特质：( 梁若瑜老师著作：十二宫六七二象 )
1.名声、科甲。
2.贵人、转环、缓和。
3.谦和、文质、书香、斯文、秀气、小巧、精致、优美。
4.优柔、犹豫、做作、矫饰。
5.大小适中。
科是一种力量的表现，非因缘。
推理解释为：
文质：是性格的表现。
理智：是性格的表现。
缓和：适用於所有的人事物。
态度：是理智平和、慢条斯理的、做事情会有细腻的一面。
作为上：要强化决断力行动力，要果敢。防犹豫不决、优柔寡断。
化科的逻辑推理：
当A宫化科入B宫时，在性格上的表现，我们可以用一句话来推理：我的A宫礼教制约於我的B宫，而我理智缓行於我的B宫。
当A宫化科入B宫时，在人事物对待关系而言，我们可以用一句话来推理：
1.就收益而言：我的A宫理智缓行於B宫，而我的B宫获得了细水长流的收获。
2.就做事态度而言：做事就会慢条斯理，精致优美，细腻。
3.就生活态度而言：文质理智的生活模式(量入为出、量力而为、计画性的消费、计画性的理财、民主式的教育、身材上是穠纤合度的、优雅的、慢条斯理的)(在精神层面上是恬淡自适)。
4.就在外表现而言：若入交友三方或行於表，则有好名声在外(科甲声名，科名在外)，形象好。
化科无法单独转忌，必须藉由化禄来带领，才能转忌到下一宫。禄科交会，慢条斯理，精美细致，甜美浪漫。权科交会，强而不锐，化暴戾为祥和，缓暴戾之气生祥和。
化科也可以由化忌来带领转忌到下一宫。科忌交会，为科忌纠缠。拖拖拉拉，剪不断理还乱，歹戏拖棚，分期付款。
生年科入迁移：科出
1.         我与生俱来就是科出，形象好，对外人都是客客气气的，很有礼貌的。男命文质彬彬，彬彬有礼。女命气质优雅、秀秀气气的。
2.         迁移是处世应对宫位，表示处理世事的手腕是温和的。
迁移科入命：
1.         迁移是社会，当我外出时，外人对我是客客气气的，有礼貌的。
2.         迁移是我的处世应对的手腕，表示我处世温文儒雅、做事谨慎、慢条斯理。
3.         社会对我的评价，是有修养的，是有品味的，名声渐渐被社会所认同与接受。
4.         迁移为福运位，际遇位，出外得遇贵人。
迁移科入兄弟：
1.         我对兄弟的态度是温文儒雅，客客气气的。所以在兄弟姊妹形象佳、名声好。
2.         我在处理事业的时候是谨慎的，平稳的。临危易逢凶化吉，绝处逢生。
3.         我在处理经济事务上是谨慎的，平稳的。临危易逢凶化吉，绝处逢生。
4.         我的体质是平妥舒适的。
迁移科入夫妻：
1.         我对配偶或异性的态度是温文儒雅，客客气气的。所以在异性间或配偶面前形象佳、名声好。
2.         我处理感情上的事谨慎的，平稳的。逢命禄、生年禄坐夫妻宫，同星曜，容易有回肠荡气的一段感情。
3.         迁移是驿马位，容易两地相思。科有缓和绵长之意。
4.         或者旧情绵绵不绝期。
5.         迁移化科入夫妻照事业。力量温文，常不论述。可论事业科出，要注重产品或事业包装行销。
迁移科入子女：
1.         我对子女（亲戚、妯娌、二婚对象、小辈）的态度是温文儒雅，客客气气的。所以子女面前形象佳、名声好。
2.         处理合伙事业谨慎，平稳。
3.         生殖系统平妥舒适。
4.         我对亲戚的态度是温文儒雅，客客气气的。
5.         若为女命，我对妯娌的态度是温文儒雅，客客气气的。
迁移科入财帛：
1.         我在处理金钱态度上是谨慎平稳的。
2.         以收入来论，际遇上的收入是涓涓滴流，不无小补，比方有小额的奖金，或是做生意四方来财，却是不多。如果没有其他强势的收入，以上班安定为好。
迁移科入疾厄：
1.         身体平妥舒适。
2.         出外容易逢凶化吉。
3.         为人处事小心谨慎。
迁移自化科：〈科出〉
1.         迁移宫本来就是行於表的宫位，为社会对我的评价，坐科，也是科出，科名在外。但自化科出，是不知不觉中、不经意中、又不分场合的表现我的科出，所以往往给人的印象有比较假斯文的感觉。
2.         处理事情的手段是温和中带有拖泥带水的现象。
迁移科入交友：
1.         我对朋友的态度是温文儒雅，客客气气的。所以外在形象佳、名声好。
2.         我会谨慎小心处理人际关系。
3.         际遇上科入交友，科有悠远绵长之意，容易有朋友久失联已久仍搭上线。他乡遇故知。悠悠故人情。
4.         若想要维系名声，容易陷入沽名钓誉。伪善矫饰。
迁移科入事业：
1.         我会谨慎处理工作或事业上的事。
2.         在际遇上我的工作或事业，容易遇到贵人相助。科主贵人。但这种贵人往往只能小有帮助而已，比方是车祸已经发生，有路人协助送医，捡回一命；又或者是我被查税，但出现贵人协助，减少损失，或经贵人协调分期缴清罚款。但是如果是化禄，则祸不临身。所以迁移或福德化禄才是真贵人。

2.         我对家人的态度是温文儒雅，客客气气的。所以在家人面前形象佳、名声好。
