第一单元  夫妻化禄入12宫
生年禄入夫妻：
1.       生年禄为我与生俱来的福。表示配偶是我福。
2.       我配偶的命宫坐生年禄。
3.       我的异性缘好，我容易得到异性的福荫。
4.       我的异性缘好，容易感情早动、或早婚。或我多情。
5.       桃花星化禄，容易桃花、享齐人之福。禄为福，当然外遇比较不容易出事。
生年禄入夫妻：
1.         婚后有如意顺遂的一面，尤其是工作或事业（照事业）。
2.         禄照事业，所以一生中工作运比较如意顺遂。
3.         夫妻为福德的财帛，所以一生中花用的金钱比较顺遂。
4.         夫妻为少小的福分，因此少小限的命宫坐禄，幼年时期较为平安顺遂，但还是得观家道兴衰。
夫妻宫化禄入命宫：（对人）
1.         我配偶的命宫化禄入命宫，等同其命宫坐生年禄。
2.         我的配偶对我很贴心、庇荫我、是我的福、贤良。
3.         我的异性朋友缘好、庇荫我、是我的福。
4.         我的感情发生得早。
5.         我容易有外遇或劈腿。
6.         以异性对象为客户的业务、或生意、或合伙人、或上司下属员工下线，我容易获得异性的庇荫。
夫妻宫化禄入命宫：（对事）
1.         结婚后容易诸事顺遂。
2.         夫妻为福分中的财，没有盖子的，容易一生衣食无缺，金钱较不余匮乏。
3.         外遇不容易出事〈有福〉。
4.         格局差，当小白脸也容易混吃喝。
5.         格局好，双妻命，得妻财。
夫妻宫化禄入疾厄宫：
1.         我配偶的命宫化禄入疾厄宫。
2.         我的配偶对我很体贴。容易常常相处再一起。
3.         我的异性朋友对我很体贴。异性缘好，久处容易生情
4.         如果夫妻化劳化禄入疾厄，我容易一夜情。
夫妻宫化禄入疾厄宫：
1.         配偶少干涉行动的自由。
2.         配偶容易发胖，也可能较懒散。
3.         婚后家运会更兴旺。（要观总体飞化）。
夫妻宫化禄入福德宫：
1.         我的配偶的命宫化禄入福德宫。
2.         我的配偶对我很窝心、是我的福、庇荫我。我们是善缘的。天赐良缘。配偶贤良。
3.         我的异性朋友也对我很窝心、是我的福、庇荫我。我们是善缘的。
4.         我容易有外遇或劈腿。
5.         以异性对象为客户的业务、或生意、或合伙人、或上司下属员工下线，我容易获得异性的庇荫。
夫妻宫化禄入福德宫：
1.         婚姻叫做天赐良缘，善缘的婚姻。
2.         婚后诸事如意。
3.         夫妻为福分中的财，没有盖子的，容易一生衣食无缺，金钱较不余匮乏。外遇不容易出事〈有福〉。
4.         格局差，当小白脸也容易混吃喝。
5.         格局好，双妻命，得妻财。
夫妻自化禄：禄出
1.         自化禄出，没有原则的好所以不挑，变动快速所以不长久，不够用心，凝聚力不足。
2.         我的配偶命宫自化禄出。
3.         我的异性缘好但不挑，但缘浅或感情不持久，对感情不够用心，彼此间的凝聚力不足。
4.         如果是桃花星化禄，容易有一夜情、或春花秋月的感情。
5.         若他宫同星曜飞忌以入，容易有第三者介入。
6.         若是我的性格宫化忌以入，则我感情执著导致意乱情迷，行为失序。易生怨或恨。
夫妻自化禄：禄出
1.         婚后对感情缘浅，或感情不持久，或对感情不够用心，彼此间的凝聚力不足。
2.         婚后夫妻间的感情看似甜蜜，因为凝聚力不足，容易出现貌合神离的现象，容易经不起考验。
3.         若他宫同星曜飞忌以入，虽然结婚了，但是感情还是容易有第三者介入。
4.         若是我的性格宫化忌以入，则我对配偶予取予求，配偶百般无奈下迁就於我。易生怨或恨。
夫妻宫化禄入兄弟宫：（人对人）
1.         我的配偶的命宫化禄入兄弟宫。
2.         我的配偶与我的兄弟相处融洽。
3.         子女宫为兄弟的夫妻，论妯娌，兄弟宫为子女的福德。妯娌彼此间的感情好。
4.         异性化禄入六亲宫位，感情容易早动。兄弟宫为父母的夫妻，是妈妈的位置。表示我的配偶与我的妈妈感情好。

1.         我的配偶福荫我的事业成就，配偶帮助我事业有成，可以夫妻共同创业。
2.         我的异性朋友福荫我的事业成就，异性朋友帮助我事业有成，可与异性友人合伙。
3.         兄弟宫为夫妻的夫妻的田宅，论主卧室。所以夫妻间的闺房之乐有很好的一面。
