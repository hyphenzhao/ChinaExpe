8.       父子间容易有代沟。
9.       父母忌入命宫，也是小人纠缠，是非多。父母属於交友三方，又是形於表的宫位。
父母宫化忌入疾厄宫：
1.         欠父母债。为父母劳碌。
2.       疾厄是情绪反应位，跟脾气有关，因此父母忌入疾厄，会对读书产生不耐烦的情绪反应，容易不爱念书。讨厌繁文缛节、不喜欢中规中矩、被束缚。夫父母也是道德规范位。
3.         父母忌入我的疾厄，有一段时间，父母会对我紧迫盯人，或唠叨、沟通不良。而我也会很烦躁。不喜欢。
4.         文书问题缠身。
5.                                               父母的命宫化忌入疾厄，父母个性劳碌。
父母宫化忌入福德宫：
1.         欠父母债。为父母操烦。
2.         福德是专属个人的兴趣嗜好位，也是情绪反应位，父母忌入福德，读书当然也会觉得很烦躁，还会东挑细检的，纸条自己喜欢的书来读，也容易把读书当成苦差事，进而不爱念书。
3.         福德是果报位，容易考运不能如愿以偿，或考试时运气不好。
4.         我与父母容易有代沟。或者恶缘。
5.         与人金钱往来要格外小心，被倒帐风险极高。容易负债。
6.         文书往来也是，比化忌入命宫还严重。
7.         父母的命宫化忌入福德。
父母宫化忌入兄弟宫：
1.         父母疼兄弟。父母忌入我的兄弟，表示在乎我的兄弟、关心我的兄弟、照顾我的兄弟、为我的兄弟操心的意思。
2.         我容易有借贷的问题，容易被倒帐，文书作保会赔钱。
3.         我父母的命宫化忌入兄弟宫。
父母宫化忌入夫妻宫：
1.         父母关心、操心、烦恼我的婚姻、或担心我的婚姻。
2.         父母干涉我的婚姻。
3.         父母反对、或不祝福我的婚姻。
4.         配偶的家庭拖累或反对我的婚姻。
5.         父母为形於表的宫位，也是社会道德规范位，所以我容易有不正常、或有问题的婚姻、或感情。
6.         我的父母对我的配偶有意见，造成我我的配偶不痛快。婚后最好是小家庭。
7.         父母的命宫化忌入夫妻。
父母宫化忌入子女宫：
1.         父母疼我的小孩。就是阿公阿嬷疼爱孙子。
2.         我不擅长教育小孩，往往对小孩疾言厉色。我的形象在小孩面前是不好的。
3.         父母的命宫化忌入子女。
父母宫化忌入财帛宫：
1.         我为父母花钱。
2.         父母担心、操心我的收入。
3.         朋友借钱不还，或借大还小，或拖拖拉拉有是非。
4.         为人作保赔钱。跟互助容易被倒。容易被倒帐。
5.         念书很辛苦，或者要自己筹措学费。
6.         文书合约、支票、背书要特别注意，吃亏、伤财。
7.         若有负债，压力比较大。容易有罚单，尤其是廉贞化忌的串连。
8.         父母的命宫化忌入财帛宫。
父母宫化忌入迁移宫：父母忌出
1.         父母憨厚耿直善良、社会地位资源不高对我没有帮助。
2.         父母忌出，对读书而言称为我读书读得不好窘困显像於外，所以我的学历可不高，或者我的学问不好，孤陋寡闻，或者我的成绩不好，属於末段班的。读书不开窍的一面。
3.         父母也是表达宫，代表我的表达窘困显像於外，所以我的表达能力不好。比较木讷寡言、或者比较严肃。冲命无奈啊！
4.         如果串连性格上的坏习惯结构就不太好了，容易有出口成脏、言辞悭吝、不学无术、形象不佳。是非多。
5.         忌入迁移宫，为运途不佳，所以往往考运不好，不利於念书、考试，尤其是关键性大考常出状况。也拙於学习观察不入微。
6.         当然上述的借贷、与人金钱往来、文书一定都要谨慎再谨慎，忌入迁移冲命，稍一不慎保证让你天不从人愿，事与愿违。最好是不要。
父母忌入交友：
1.         父母干涉我的人际交往。
2.         父母关心、操心、担心我的人际交往。
3.         父母能够帮助我的人脉资源有限。
4.         我的表达造成朋友的困扰，容易措辞不当。
5.         我有不擅长人际攀缘的一面。也有可能交错朋友，引发众人议论，冲库位，可能朋友是爱乱花钱，或者我不善理财，交朋友间花费很大。
6.         我的读数学习造成交友坐忌，表示不利於考试竞争。
7.         父母化忌入交友，容易有人际是非。修养不好、措辞不当、形象不佳、表达不够婉转，造成人际间困扰。
8.         当然上述的借贷、与人金钱往来、文书一定都要谨慎再谨慎，忌入交友冲兄弟库位，稍一不慎保证让你赔大钱(库位忌出，表示大笔支出)。最好是不要。
9.         父母的命宫化忌入交友。
父母忌入事业：
1.         父母操心、关心、担心我的工作或事业。
2.         父母带给我工作或事业的压力大。(通常是上司、老板)。
3.         文书合约牵绊我的工作或事业发展，比如说竞业条款、或旋转门条款。
4.         须帮父母分忧解劳。也须尽孝养之责。父母忌入命，为父母劳心。父母忌入财帛，要为父母花钱。父母忌入事业，孝养父母是我的工作。
5.         读书学习比较辛苦，容易半工半读，边工作边读书。把读书当成工作一样每天做。
6.         父母的命宫化忌入事业。
父母忌入田宅：
1.         父母关心、操心、担心我的家庭或经济。
2.         父母忌入田宅，就是父母在我家，我必须尽孝养
