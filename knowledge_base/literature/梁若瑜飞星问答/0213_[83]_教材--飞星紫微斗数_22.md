>※ 引述<梁若瑜(liangs40111)>之铭言：  >>※ 引述<gchang01.tw(gchang01.tw)>之铭言：  >>小弟刚刚接触紫微没多久 也对如何观察依命盘的优缺点较难掌握 ( 老师 "体" "用" 之说,小弟也有拜读，但是融会贯通需要一点时间)  >>  >>之前小弟看一好友的命盘, 他目前任职 外商服务业，但是因为全球化的关系，管理职都归到国外，总觉不得志，现认真考虑未来自行创业或是继续吃人头路的可能性  >>  >>其命为：男命国历57年阴历六月二日寅时。天府在巳逢右弼化科，天机化忌在本命奴仆宫，  >>小弟初步的观察，本命天府显示此人个性保守，天相陷於官禄，天机忌於奴仆宫主不得下属帮助，地劫入财帛主财来财去，固小弟觉得小弟好友是乎不适合自行创业  >>  >>但是小弟对大运流年还不太会看，不敢乱说  >>  >>敢问老师就此命盘，是否持同样的看法? 或指点更多的方向 ? 感激不尽  >>  >答：从你的措辞间可以看出三合派观念甚重。譬如「奴仆宫」它绝对不只是说属下，他是泛指一切人际关系，故而我们改称之为「交友宫」是有它的道理。  >创业需看其收藏〈田宅〉三方是否牢靠？此命既以生年忌坐交友冲兄弟库位，守财不牢！再者田宅以庚天同忌入父母〈冲疾厄也是不牢靠，常生异动之念〉，转戊天机再忌於交友会生年忌，成双忌冲兄弟库位，收藏见破不吉。  >而生年忌坐交友，转壬武曲忌入福德冲财帛，守财不牢必生苦。再串联於田宅之破成双忌，少能存余粮，如何创业？  >此命於人惜情过重，无奸如何成商？基本格局就不是块好料子，上班安定才是福！  通过这个例子，大致了解创业要看田宅宫三方。手头无大企业家的例子，体会不深。

P116：2005/12/07：标　　题：Re:看盘的思路是什麽？
>>>>>>>>>恩师，学生面对一个盘，还是不知道如何下手观察，请老师再谈看盘之思路，最好举例子。为盼！  >>>>>>>>>  >>>>>>>>答：前面早已提过，是漫不经心还是贵人多忘？  >>>>>>>>先找格局的优点与缺点〈体〉，再看吉凶之应於何限何年〈用〉？  >>>>>>>恩师，非学生漫不经心，学生目前对於有些盘格局优缺点不知如何观察？  >>>>>>>今早观察一个命盘，女命国历61年阴历七月五日寅时。天梁在午逢生年禄，生年忌在本命奴仆宫，此命格局的优点与缺点是什麽？吉凶不明。  >>>>>>>或者恩师自举例再谈。  >>>>>>>>  >>>>>>>学生之盘已明，缺点一定注意，感谢恩师，学生太感兴趣飞星斗数了。  >>>>>>>  >>>>>>答：如果生辰精准的话，此61年女命，生年禄既入命，好沟通而人缘佳〈命为交友的疾厄，得禄自是与人相处愉快〉。命挟禄以丙廉贞〈桃花星〉忌入父母〈形於外之宫〉，桃花气质不免形於色。第二大限踏兄弟宫，则第二大限父母禄应原命父母，春风吻上脸。  >>>>  >>>>>此人民国82年9月份出国，民国91年移民国外，不知如何推算？请老师指点  >>>>>  >>>>答：本命迁移壬天梁化禄入命，出外缘佳；转丙廉贞忌入父母〈迁移共宗六位〉，复得夫妻宫〈迁移的事业―出外运位〉甲廉贞飞禄来会，更言其出外缘旺。  >>>>82年22岁大限转入夫妻宫，则本命迁移缘之入命与大限命吉化相交会矣。22岁流年疾厄〈夫妻宫―大限命〉，吉化应照於本命疾厄，动其身也。八月踏原命迁移飞禄入命，九月则本命迁移禄入命而转照於流月迁移，此二个月驿马缘浓。  >>>>91年31岁移民国外，大限仍踏夫妻宫，流年入原命宫坐迁移飞来之禄，则本命、大命与流命吉化庆会矣。  >>>>然迁移以壬飞武曲逢生年忌呈双忌於交友，谓之出外缘有破，非稳定之象。虽移民国外，於外地恐仍有所变动而再移居异方。  >>>>此命之败笔处：财帛以壬武曲逢生年忌呈双忌於交友〈冲库―兄弟收藏宫〉，财多不畜；转辛文昌呈双忌入福德，必有财苦。而迁移亦以壬武曲再忌於交友，更破财局，防露窘态〈迁移形於外〉、失信於人。  >>>>本大限行於子女宫，大限交友〈福德宫〉得多忌冲大限兄弟库位〈财帛宫〉，但防经济混乱。37岁再踏原命迁移，势恐不妙。  >>>>  >>>谢恩师指点！  >>>此女民国87年阳历4月份注册结婚，阳6月份婚礼。长辈为媒，今年丈夫事业上春风得意。还请恩师指点手法！  >>>  >>答：27岁流年踏财帛宫结婚，乃流年夫妻〈本命迁移〉以壬天梁飞禄入大限「福德」〈本命宫〉，天降姻缘，转而丙廉贞忌入父母〈婚姻的田宅〉；而流年「福德」〈本命夫妻、大限命宫〉，以甲廉贞禄入父母作吉会，成就婚姻田宅的美事。本命迁移之禄转吉会〈本命父母〉而照而四月命宫〈本命疾厄〉，故婚。  >>  >>注：迁移之禄入命乃天降之福，为流年夫妻宫，是言此年结婚为极美正缘，可喜也。否则此命之夫妻甲太阳化忌冲命，转而壬武曲逢生年呈双忌於交友，夫妻之情将薄如纸。何作此言？乃婚姻忌出〈忌入迁移〉而后破婚姻共宗六位〈交友〉故也。是以类此婚姻必以聚少离多的相处为上策，多聚防同床而异梦。  >>  >>其夫如为上班族，今年当然事业得意；如为自己当老板，还防虚而不实，终究一场空欢喜。何言空欢喜？  >>上式言及夫妻忌出冲命，转而双忌於交友冲兄弟〈事业共宗六位〉，此象亦指其夫命格破库，创业终尝败绩。  >>如为上班族〈无风险〉，则本命夫妻宫〈大限父母〉以禄飞入父母〈表象宫〉，言其可人和悦；而其福德〈本命宫〉之挟天梁禄转来会父母，可称为善袖舞者，亲和圆融，大助於事业的汲营交际。  >>则大限父母吉应本命父母，本命夫妻吉应流年夫妻，故今年自是春风得意。  >学生感慨恩师下笔言之有理有据。此人丈夫为上班族。  >能否借此盘指点一下有无创业运？那类命盘适合创业？  >此人子女运如何？会怀孕吗？
