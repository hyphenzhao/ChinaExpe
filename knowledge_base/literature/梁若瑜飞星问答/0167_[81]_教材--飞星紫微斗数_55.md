交友宫化禄入财帛宫：
1.         交友带给我收入好，或用钱（手头）方便，所以如果我开店做生意，朋友来自四面八方，所以我们成为四方来财。容易是做生意的人。
2.         财帛为汲营三方，是现金缘位，交友化禄而来，代表我在赚钱上的人缘很好，客源多，适合做现金生意。
3.         同业或同行竞争得利。
4.         容易与朋友有金钱往来频繁，或朋友对金钱比较不会计较。
5.       我交友的命宫化禄入财帛，我容易结交到手头很方便的朋友。也容易多交做生意的朋友。
交友宫化禄入疾厄宫：
1.         朋友常常亲近我，喜欢跟我相处在一起，也表示我与人相处亲和，人缘好。
2.         如果是异性，容易有肢体的接触，容易擦枪走火，尤其是交友化贪狼、或廉贞禄。
3.                                                                 容易交往个性「温和」、「好相处」的朋友。
4.                                                                 可从事服饰、精品及咖啡、茶艺、餐饮、休闲、娱乐等服务业。
交友宫化禄入迁移宫：
1.         交友禄入迁移照命宫，我的社交圈很广，容易得到朋友的庇荫（帮助），多得贵人相助。交友宫也是我对人际交往的态度，交友禄入迁移，因友而乐、而亲和，所以我比较喜欢热热闹闹的，与朋友相处很快乐的表现在脸上。
2.         我的朋友大多亲和开朗、外缘好。
3.         我的朋友大多在社会上有身分、有地位。
4.         我的社会关系好、人脉佳。
5.         交友为夫妻的疾厄，化禄入迁移，表示我的配偶个性随和好相处。
交友宫化禄入事业宫：
1.         我的朋友庇荫我的事业或工作顺遂，容易交往到做生意的朋友。
2.                                                                 在事业或工作上，人气很旺，人缘好，所以可以组织团队。
3.                                                                 利於同行、同业的竞争。
4.                                                                 利於与友合伙事业发展。
5.                                                                 我的朋友大多事业或工作如意顺遂。
6.                                                                 交友为父母的事业，容易得到父母事业之庇荫。
7.                                                                 交友为夫妻的疾厄，我的配偶工作轻松如意顺遂。
交友宫化禄入田宅宫：
1.         我的朋友喜欢来我家，我家让我的朋友很快乐。家庭人气旺，好客、人缘好。
2.         田宅为我的生活居家环境，容易有从小到大一起长大的朋友。
3.         我若开店做生意，我的生意有很多老顾客，四方来财，生意兴隆
4.         亲戚、朋友、邻居多往来和睦且热络。
5.         有利於与朋友合伙，共同经营事业。
6.                                                                 我的朋友大多家庭经济蛮好的，或者我容易与富者仳临而居。
7.       可从事餐饮、饭店、旅馆、咖啡、茶艺、休闲产业。
8.       从事不动产行业，最好要有偏财星化禄。
