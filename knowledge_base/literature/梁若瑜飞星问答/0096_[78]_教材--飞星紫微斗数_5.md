# [78] 教材--飞星紫微斗数

事态更为严重。
化科的逻辑推理：
当A宫化科入B宫时，在性格【命宫、福德】上的表现，我们可以用一句话来推理：我的A宫礼教制约於我的B宫，而我理智缓行於我的B宫。
当A宫化科入B宫时，在人事物对待关系而言，我们可以用下列方式来推理：
就收益而言：我的A宫缓行於B宫，而我的B宫获得了细水长流的收获。
就做事态度而言：做事就会慢条斯理，精致优美。
就生活态度而言：文质理智的生活模式(量入为出、量力而为、计画性的消费、计画性的理财、民主式的教育、身材上是穠纤合度的、优雅的、慢条斯理的)(在精神层面上是恬淡自适)。
就在外表现而言：若化科入交友三方或行於表，则有某方面的好名声在外(科甲声名，科名在外)。
化科无法单独转忌，必须藉由化禄来带领，才能转忌到下一宫。禄科交会，慢条斯理，精美细致，甜美浪漫。
化科也可以由化忌来带领转忌到下一宫。科忌交会，为科忌纠缠。拖拖拉拉，剪不断理还乱，拖拖拉拉，分期付款。
化忌的逻辑推理：
当A宫化忌入B宫时，我们可以用一句话来推理：
就性格【命宫、福德、疾厄】而言：我的A宫在乎 ( 执著於 ) 我的B宫，而我必须为B宫付出。
就人事物而言：我的A宫歛藏於我的B宫，而我必须以A宫之人事物为我的B宫付出。
一忌为劳：约坐守，为「守成」或「欠债」、「付出」〈红尘的当然耳事〉。一忌不会造成生活上的困扰。比如说命忌入田宅，为我顾家守成，当然是好。比如说财帛化忌入田宅或兄弟，为我是勤俭储蓄持家的个性当然好。比如说田宅化忌入兄弟或财帛为退财，表示我不善理财的多耗用，是花费比较大的意思，不善理财，比较不节俭，也还不主凶，两忌以上就不好了。
二忌为病：同宫或两对宫串联，就是「破、败」的开始，个性必然有扭曲之象，偏离中道。2忌为病是表示已经出现了 ( 过度 ) 的意思了，或者 ( 不理性的 ) 处事应对，造成了诸多的困扰，但还没呈现破局。如人的身体出现了酸痛啦、疲劳啦、常常拉肚子啦、常常便秘啦、常常放臭屁啦、、、等现象，这时需要看门诊，调整生活作息或饮食，还不到要住院给医生修理的状态。财务状况就有紧张的感觉了，压力就来了，还不至於不够用，若转忌忌出，则可能出现月光族的现象。
三忌为破：同宫或两对宫串联，则「大势不妙」，败象已露。破败是出现大漏洞了，非得修补不可了。如人生病，到症状已经很明显了，身体无法正常作息饮食，苦不堪言了，必须得住院让医生来进行身体维修了。若是财务状况已经空虚，甚至窘态已露，寅吃卯粮，挖东墙补西墙，危机重重，若串连父母(交友财)，可以有轻微的负债了。
四忌为败：同宫或两对宫串联，常面临「生死」、「去留」。4忌为败局已经呈现，如同人生病已经进入加护病房，生死一线之间了，除非福厚来解，否则将一去不复返，空留遗憾。对财务而言，已经走到破产的边缘、或者已经负债累累了，如果转忌忌出，则容易因破产或负债而跑路。
五忌以上：则必江山尽失。时间一到很难挽回。
多忌串联，不同宫位的串联，不同的事态上，不同的时空，所呈现的轻重会有所不同。这就需要经验的累积。
化忌必须转忌，追根究柢其事态发展的方向，与事态发展的轻重程度。
A宫化忌入B宫，转忌入C宫。其解释分四个层面：
A宫化忌入B宫
B宫化忌入C宫
A宫化忌入C宫，透过B宫。
A宫化忌入B宫，追根究柢到C宫。(此项为主要论述)
在命盘的解释上，因为有六亲、交友人际，所以论述时会有三个层面的对待关系
对我而言是什么事
对他而言是什么事
我和他的对待关系
论六七二象时，因为还没有论到时间，也就是动盘的契应，所以我们会常常用两句话来说，
有一面
有一天
在论命时，由於尚未确认命盘与命主是否相符，所以我们常说：如果这个命盘对的话，他可能有什么现象，或者是什么现象？
解释象义时，想简单一点，比如说迁移宫，它可能有10个象义，我在当下只想一个就好了，我想到哪一个就哪一个。还可以归纳出一个简单的思维，从人性的角度先思考，我们就先针对【对我而言是什么事】来思考推理，比如
命宫的四化：主心之所向、思考、情绪反应【内心反应喜怒哀乐】。
命宫化禄入某宫：我对某宫是多情的(心)，做某宫的事会快乐 ( 容易顺心 )。
命宫化权入某宫：我对某宫是积极，想要掌控某宫。
命宫化科入某宫：我对某宫是理智的，我会理智的处理某宫的事。
命宫化忌入某宫：我对某宫是执著的，我甘愿为某宫付出。
疾厄宫的四化：主肉身、相处、情绪反应 ( 身体 )。
疾厄化禄入某宫：我对某宫是多情的(身体)，我的身体昌常接触或做某宫的事而快乐。
疾厄化权入某宫：我在某宫的事上特别有活力的 ( 体力旺盛的表现在哪哩 )。
疾厄化科入某宫：我在某宫的事上行为动作是慢条斯理。
疾厄化忌入某宫：我对某宫是执著的 ( 身体 )，我的体力付出在某宫的事上面，但肢体动作 ( 相处 ) 却是冷淡的。
福德宫的四化：主秉性 ( 天性 )、兴趣嗜好享受、情绪反应 ( 精神 )。
福德化禄入某宫：我对某宫是多情的 ( 精神 )，做某宫的事会非常快乐 ( 容易悟到 )。
福德化权入某宫：我对某宫是非常积极的，想要强势的掌控某宫。对人的宫位为强出头。
福德化科入某宫：我对某宫看得很恬淡的，我会恬淡的处理某宫的事务。
福德化忌入某宫：我对某宫是偏激执著的，我盲目地甘愿为某宫付出。是一种偏激的执著，具有忧疑、挑剔的个性特质。尤其是太阴巨门，及廉贞或贪狼之化。
迁移宫的四化：处世应对的能力、社会资源、驿马缘。
迁移化禄入某宫：我擅长主动攀某宫的缘，圆融处事。
迁移化权入某宫：我擅长处理某宫的事，强势、活跃、主导某宫的事
迁移化科入某宫：我温和的处理某宫的事。
4. 迁移化忌入某宫：我不善攀某宫缘，我不善处理某宫的事，手法拙劣(2忌以上)。

兄弟化禄入某宫：兄弟带给我某宫的快乐。

兄弟化科入某宫：兄弟对我某宫的事不无小补。
