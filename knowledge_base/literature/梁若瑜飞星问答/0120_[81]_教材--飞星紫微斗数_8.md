# [81] 教材--飞星紫微斗数

壮盛。
化权无法单独转忌，必须藉由化禄的带领，才可以因为化禄是机缘，在机缘的带领转忌到下一宫。此时禄权同星曜的交会，我们称为禄权交拱。
禄是因缘、机缘、舞台，嫩叶新枝，充满希望，却是脆弱的，权是能力、能量、力量，犹如保护的措施，让禄得以顺利的发展，扎扎实实的呈现出华丽的结果。有了能力要有舞台，有了机会要有能力才能发展，因此禄喜权护，权喜禄缘，交织出华丽而扎实的结果。
化忌也可以带权，权忌争战，让整件事呈现激化的状态，其破坏力被强化了，导致事态更为严重。
财帛权入命：我的财帛宫成就於我的命宫，而使我的命宫壮盛
1.     表示我的收入好，让我有自信。水帮鱼，鱼帮水，所以也表示我的能力强，所以收入好。做生意想做高利润的。适合分红、佣金收入的行业。
2.     内心有了自信，有了好收入，自然就会展现积极企图心，拓展事业版图。所以适合开发、领导与销售的工作。有利於升迁或创业。
3.     财帛化权，表示我赚钱的能力、模样、方式，权以性格的角度来看是掌控，适合发展专业技能，拥有专业技能，容易创造高薪，或高职位。
财帛权入兄弟：我的财帛宫成就於我的兄弟宫，而使我的兄弟宫壮盛
1.     兄弟为财库位，所以表示我常有大笔的收入，挹注我的财库，使我的经济能力越来越好。适合分红、佣金收入的行业。
2.     兄弟为我的事业成就位，财帛为汲营三方之一，因此我容易展现对事业的积极企图心，甚至开创事业。
3.     财帛化权，表示我赚钱的能力、模样、方式，权以性格的角度来看是掌控，适合发展专业技能，拥有专业技能，容易创造高薪，或高职位。
财帛权入夫妻：我的财帛宫成就於我的夫妻宫，而使我的夫妻宫壮盛
1.     代表我婚后收入可以更高、更好，让我的配偶更有自信。配偶不用为花用钱烦恼。
2.     权入夫妻照事业，我会主动积极努力地赚钱，让我的工作顺遂。
财帛权入子女：我的财帛宫成就於我的子女宫，而使我的子女宫壮盛
1.     我用金钱来成就我的子女，对晚辈，我们的成就方式，是用栽培或帮助的。注意是否给小孩的用度过多。
2.     财帛权入子女，为田宅权出，库位权出，子女为人际三方，所以比较会敢赚敢花，尤其在人际间，也会比较大笔的花用。如果会迁移、父母的禄，则容易虚华(场面铺张)浪费。
财帛自化权：〈权出〉
1.     自化权出，就是不知不觉的表现我财帛的权，且不分场合的表现出来，所以是一种不用心的表现。
2.     就花钱的角度而言，容易大笔支出。不会用心理财，所以务必养成储蓄的习惯。
3.     就赚钱的角度而言，容易大笔进帐。
4.     权出，有变动快速之意，所以适合现金生意，如现金切货、脱手的循环生财，最好发展潮流、时尚等领先市场的产品销售，就是所谓的【时机财】。需要不断推陈出新。
5.     就赚钱的能力而言，适合培养专业技能，容易获得高薪或高职位。但因为是自化权出，容易虎头蛇尾，或没有长远的计画与管理，不能持久，所以也适合稳定上班领薪水。
财帛权入疾厄：我的财帛宫成就於我的疾厄宫，而使我的疾厄宫壮盛
1.     赚钱的事让我充满活力、干劲，又可以好收入。疾厄有权，抗压性高，不怕劳累。适合分红、佣金收入的行业。
2.     财帛化权，表示我赚钱的能力、模样、方式，权以性格的角度来看是掌控，适合发展专业技能，拥有专业技能，容易创造高薪，或高职，又疾厄坐权，充满活力干劲，所以也是耗体力的技术性工作者。
3.     个性属於主动、干脆的人。
财帛权入迁移：我的财帛宫成就於我的迁移宫，而使我的迁移宫壮盛
1.     我的钱在社会上是亮丽的，因此钱容易花在可以展现身分地位的象徵上面，比方说穿戴名牌、用高档的东西、吃高档食材或进高档餐厅，这都在在显示了我的高收入，赚钱能力好，因此我的支出能力强，信用佳。
2.     赚钱能力展现在外，展现我的积极、自信。
3.     财帛化权，表示我赚钱的能力、模样、方式，权以性格的角度来看是掌控，适合发展专业技能，拥有专业技能，容易创造高薪，或高职，也容易展现我在专业上的敏锐观察力、决断力强。另外我的专业技能权出，表示展现於社会，因此有利於专利的申请。有了专利产品，收入更好。
4.     格局好，善於汲营，容易大笔钱进出。格局不佳，中看不重用，或者容易是银行的理财专员。
财帛权入交友：我的财帛宫成就於我的交友宫，而使我的交友宫壮盛
1.     我大笔金额帮助我的朋友。容易是用钱交朋友，在人际间很活跃，但须防金钱露白，招盗引贼。
2.     财帛化权入交友，为兄弟(库位)权出，因此我容易大笔支出，信用好。适合大手笔、批发或高价位的生意。
3.     财帛化权入交友，为兄弟(库位)权出，交友为人际三方，所以比较会敢赚敢花，尤其在人际间，也会比较大笔的花用。如果会迁移、父母的禄，则容易虚华(场面铺张)浪费。
财帛权入事业：我的财帛宫成就於我的事业宫，而使我的事业宫壮盛
1.     我的钱成就我的事业，容易用钱投资事业，事业越做越大，适合将钱投资在事业上。
2.     财帛化权，表示我赚钱的能力、模样、方式，权以性格的角度来看是掌控，适合发展专业技能，拥有专业技能，容易创造高薪，或高职位，也适合分红收入。
3.     对事业展现积极的企图心，也容易升迁、创业。
4.     适合市场开发、领导的工作性质。
财帛权入田宅：我的财帛宫成就於我的田宅宫，而使我的田宅宫壮盛
1.     我的钱成就我的财产，容易用钱滚钱，财产越来越多。适合将钱投资在房地产上。所以慢慢地就学会理财、活用於房地产的经营上，获得高收入。
2.     我积极展现企图心在创造财富上。
3.     财帛化权，表示我赚钱的能力、模样、方式，权以性格的角度来看是掌控，适合发展专业技能，拥有专业技能，容易创造高薪，或高职位，也适合分红收入。
4.     用钱让房子变大，所以有装潢、增建、再置产、换更大房子的现象。
财帛权入福德：我的财帛宫成就於我的福德宫，而使我的福德宫壮盛
1.     赚钱的事情让我充满活力、态度积极、企图心强。
2.     赚钱的事情让我好胜，所以我会比较爱体面、爱表现、敢赚敢花。
