# [81] 教材--飞星紫微斗数

象中为【夏天】，是属『火』旺之象，万物壮盛，充满力量。
1.自信、主见、企图、抱负、积极、欲望。
2.领导、开创、拓展、突破、结实、壮大、权力、地位。
3.主观、能力、应变、果断、刚毅。
4.胆识、行动、运动、强硬、霸气、尖锐、争斗。
5.大的、新的、多的、好的。
推理解释为：
壮盛：用Power来形容也蛮贴切的。
掌控：性格上的表现(命宫、福德宫，具有思考能力。迁移宫是处世应对的能力)。
成就於：人事物，均可适用。
权是一种力量的表现，非因缘。
权的态度是积极的。
作为上：要圆融柔和、谦虚、防霸气，冲动行事。
化权的逻辑推理：
•   当A宫化权入B宫时，在性格的表现上，我们可以用一句话来推理：我的A宫积极於B宫，而欲掌控B宫。
•   当A宫化权入B宫时，在人事物上对我而言，我们可以用一句话来推理：我的A宫成就於我的B宫，而使我的B宫壮盛。
化权无法单独转忌，必须藉由化禄的带领，才可以因为化禄是机缘，在机缘的带领转忌到下一宫。此时禄权的交会，我们称为禄权交拱。禄是因缘，权是力量是能力，禄是机缘、舞台，嫩叶新枝，充满希望，却是脆弱的，权是能力、能量、力量，犹如保护的措施，让禄得以顺利的发展，扎扎实实的呈现出华丽的结果。有了能力要有舞台，有了机会要有能力才能发展，因此禄喜权护，权喜禄缘，交织出华丽而扎实的结果。
化忌也可以带权，权忌争战，让整件事呈现激化的状态，其破坏力被强化了，导致事态更为严重。
生年权坐父母宫：
1.         生年四化是与生俱来的，说话容易得理不饶人、傲慢、尖锐、不谦虚，个性太冲。逢忌则容易草莽性格（粗鲁）。
2.         父母为学习宫、读书宫、涵养宫，由於上式的个性，所以要多读圣贤书（智慧之学），则谈吐有物、仗义直言。或学习专业、专技，则更具说服力。
3.         父母坐权或化权，容易理科较强，当然要综观全局。格局好，有利於念书、考试、公职。证照的取得。
4.         若逢福德化忌来会，容易粗鲁、易怒、秽言、无礼。福德化忌入父母为忌出，容易偏激燥烈。
5.         父母的命宫坐生年权。
父母宫化权入命宫：
1.         父母对我的管教甚严。或师长对我要求较高。
2.         父母、长辈、老板、上司成就我，提携我，有利於我的升迁。
3.         父母为学术上的学习，化权入命，学术成就我，所以在专业涵养上有利於立足社会，所以最好学有专精，建立自己的专业。
4.         有利於读书、学历、考证照、公职。有利於与公家机关生意往来。
5.         父母为夫妻的田宅，容易得到亲家的助力成就我。
6.         父母的命宫化权入命宫，等同父母的命宫坐生年权。
父母宫化权入兄弟宫：
1.         父母对我的兄弟管教甚严。
2.         我父母成就我的兄弟。
3.         我的长辈、老板、上司成就我的事业，提携我，我容易在事业上获得提拔。
4.         父母为交友财，所以我容易获得大额的银行贷款，或者长辈对我经济上很有帮助。
5.         父母为夫妻的田宅，我的亲家庇荫我的事业或经济。
6.         夫母命宫化权入兄弟宫。
父母宫化权入夫妻宫：
1.         父母干涉、促成、主导我的婚姻。
2.         父母化权入夫妻照事业，我容易获得父母、长辈、老板、上司成就我的事业。
3.         我容易获得亲家帮助我事业。
4.         容易公证结婚，尤其是会（忌）。
5.         父母的命宫化权入夫妻。
父母宫化权入子女宫：
1.         我的父母对我的小孩管教甚严。
2.         我容易训诫我的小孩。（父母是表达宫，化禄是亲和的表达模式。化权是训诫。化科是温和的表达，言教重於身教，民主式的，讲道理的。化忌是拙於表达，容易不得要领，疾言厉色，形象较差）
3.         我的子女容易遇到严格的师长。
4.         父母的命宫化权入子女。
父母宫化权入财帛宫：
1.         我小时候，父母给我的零用钱很多。
2.         容易遇到的老板、或上司成就我的收入好，帮我加薪。
3.         我容易与朋友有大笔金钱往来，活银行贷款，信用良好。
4.         我可从事银发族的相关事业。
5.         父母为交友财，我可以从事受委托金融理财的相关业务。
6.         亲家荫我收入好。（条件要有果报化禄来会）
7.         父母为学术上的学习，化权入命三方，学术成就我的收入，所以在专业涵养上有利於立足社会收入好，所以最好学有专精，建立自己的专业。
8.         交友三方化权入财帛，均有利於高价位的产品销售。父母、迁移为形於表的宫位，化禄权入命三方者，可以从事高格调的产品销售。
9.         父母的命宫化权入财帛。
父母宫化权入疾厄宫：权出
1.         疾厄是身体的我，父母会管我，或干涉我的行动，或紧迫盯人。
2.         以读书立场想，你会较拼，比较有活力，所以抗压性比较强。
3.         以面子立场想，你会不低头，意志力比较强。
4.         父母为读书宫、涵养宫，读圣贤书，容易守为分明（权出）。
5.         父母的命宫化权入疾厄。
父母宫化权入迁移宫：权出
1.         父母的成就好、地位高、社会资源丰厚，庇荫我、成就我。
2.         有利於念书、考试，公职、升迁、证照取得。以其权出，格局好，容易表现出色。
3.         父母权出，格局好，容易拥有高学经历、学有专精，容易受老板、或上司的提拔升迁，当然就容易高职、高薪。
4.         亲家在社会上的成就好、地位高、社会资源丰厚，庇荫我、成就我。
5.         会禄：则术德兼修，迁移坐禄（生年禄、或命禄），为人处世圆融。亲和大方。
6.         会忌：则说话臭屁老是喜欢占上风、或出言傲慢、说大话、修养差。迁移有忌，耿直，拙於处世。逢权则冲动粗枝大叶。
7.         父母命宫化权入迁移。
