# 论杂气

杂气者，盖谓辰戌丑未之位也！辰中乙癸戊字，戌中辛丁戊字，丑中有癸辛己字，未中有丁己乙字；此四者，天地不正之气也。

且如甲则镇于寅位陽木之垣，乙专镇于卯，皆司春令，而夺东方之气；辰为东南之隅，及春夏交 接之界，受气不纯，禀命不一，故名“杂气”也。丑戌未亦然。

虽看六甲何如以论之？假日干是甲，而得丑月，贵既在中；辛则为正官，癸为之印绶，己则为正财。不知用何者为福？要在四柱中看透出是何字，随其所出，而言其吉凶。有如前说法，但库中物皆闭藏，须待有以开其扃钥，方言发福；所以开扃钥者，何物也？乃刑冲破害耳。

且如四柱中元有刑冲破害，复行此等运气；则刑冲破害多，反伤其福。

大抵杂气要财多，便是贵命；若年时别入他格，当以他格例断之。盖此乃天地之杂气，不能统一，故少力耳！

别格专于时年，乃重事。

看命须审轻重，以取祸福；先论重者，次言轻者，百发百中矣！其它当以言类之。
