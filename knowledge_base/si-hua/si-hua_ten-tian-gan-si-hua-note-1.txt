★ 甲天干

甲干凡是甲年出生的人大多聪明慧黠，自视甚高，行事风格多变，不按牌理出牌，有创意，多情善感。

甲天干令太阳化忌，但由于太阳星是官贵之星却化忌，所以一生难免为事业奔忙，行走江湖身不由己，由于热情热心又爱现，容易识人不明误交损友，很有被人横刀夺爱之虞。

加上自己总是要为生活工作忙禄，经常早出晚归的，让心爱之人独守空闺而内心生出许多怨尤。

因此，情变多因工作忙碌缺乏沟通，没有时间培养感情所致。

★ 甲干生人

1. 主偏财、投机行业。

2. 眼疾、近视、血压。

3. 儿女私情，易有失恋现象，尤其在夫妻宫。太阳化忌则初恋不易结合，一生情困。

4. 甲干在夫妻宫，易娶长女或嫁长子。

5. 因太阳化忌，不利男命。

★ 甲干四化

✪ 廉贞化禄

1. 利于考试、留学、官运，地位高升名气扬。

2. 宜任公职或公家机构作生意，有不劳而获之财。

3. 适宜从事电脑科技事业、贸易生意或渔业生意。

4. 大限十年财禄充沛，官运通达，流年一年吉祥如意。

✪ 破军化权

1. 个性刚强，用钱大方，财来财去，成就名声佳。

2. 在夫妻宫夫妻个性强，多争执，不相让。

3. 在子女宫子女顽皮好动，不易屈服而霸道。

4. 女命适合企业主管。

5. 大限十年开创事业，激进有所成。流年一年如意。

✪ 武曲化科

1. 有财与库、及有贵人相助，逢灾难能解厄。喜存私房钱或存入银行及邮局。

2. 适合在金融界上班，或从事文化事业方面（补习班）有利进财。

3. 大限十年顺利，名气远播，贵人相助提拔，流年一年通顺发达。

✪ 太阳化忌

1. 眼疾近视，头痛失眠，心情烦燥而不安。

2. 不利父、夫、子。

3. 大限十年奔波劳碌，流年一年不如意。

4. 逢天刑有牢狱之灾，运途不佳多变化。

5. 不利仕途及感情，易有失恋现象，心情不稳定，容易生气。 。

★ 乙天干

乙干乙天干令太阴化忌，太阴星是代表家庭、情感的星曜，若是化忌的话，感性多情又执着，容易情绪不稳，过于完美主义又爱钻牛角尖，经常吹毛求疵的让人受不了。

而且太阴星是个夜猫族，喜欢夜不归营，容易流连灯红酒绿的场合，让人捉摸不定很没安全感，是感情的致命伤。

★ 乙干生人

1. 艺术才华，适宜教育界及技术专业技能。

2. 易有宗教缘。

3. 太阴化忌：

不利女命，参考化忌在何宫。也要注意眼疾近视。

若化忌在疾厄宫有痔疮（男性则肾亏）。

若化忌在子女宫易得妇女病、尿路系统疾病、糖尿病。

若化忌在父母宫注意父母尿路系统疾病。

★ 乙干四化

✪ 天机化禄

1. 利于变动，适合参谋，或靠智慧的行业；或在铁类、五金、汽机业的技术上发财；也可在五术方面进财；或在稳定有计划之行业上成就。

2. 十年事业发达，流年一年得意。

✪ 天梁化权

1. 男女命都好打不平，肯为人排纷解难，有点固执，主观强，做事有原则。

2. 适宜从事法官、律师、教师、宗教界或在公教机构上班。

3. 大限十年通达，流年一年称心如意。

✪ 紫微化科

1. 主博学多能；文学研究，步步高升，名声远播。

2. 易受贵人提拔，爱惜面子，与人接洽和睦。

3. 大限十年文事鼎盛，流年一年平顺。

✪ 太阴化忌

1. 一生劳碌，身体较弱。

2. 男命主迟婚，女命主失权，不受重视。

3. 不利女性，母、妻、女主凶象。

4. 易有破耗、疾病，家运多变动，不安定，时常搬家。

5. 不适合经营房地产事业。

6. 大限十年阻滞，流年一年不如意。

★ 丙天干

丙干丙天干令廉贞化忌，廉贞星是个聪明又自负，相当感性而多情的星曜，一旦化忌就情关难逃，容易为情所困而作茧自缚。

且廉贞星天生占有欲强，化忌时难免掀起醋江醋海，以其刚烈的性格，很容易想不开而走极端，会做出什么傻事还真叫人难防。

★ 丙干生人

1. 适宜投机行业或在技术上进财或为学者。

2. 天机化权：属智慧，可考虑幕后军师、设计、企划。

3. 天同化禄为福星，不能自化（自化就无福禄）。

4. 廉贞化忌：注意交通罚单，官非刑罚。

★ 丙干四化

✪ 天同化禄

1. 有无形的福气，食禄佳，有不劳而获之财，利于计划实现，享受成果。

2. 适宜公教上班、医生或餐饮业。

3. 大限十年光彩如意，流年一年福份安逸。

✪ 天机化权

1. 主掌机要之权势，凡事积极采主动，机智能力强。

2. 适合五术、宗教、技术行业。

3. 大限十年权势发达，利于竞选活动，流年一年如意吉祥。

✪ 文昌化科

1. 有才识、学问好、利考试，竞选易当选。

2. 往文路发展得名，往出版业发展则发达利市。

3. 大限十年文风兴盛，流年一年如意。

✪ 廉贞化忌

1. 经商劳碌，不利公职，官场有是非贬职。加会天刑星，刑扙难逃。

2. 在迁移宫化忌加会煞星，有凶险、脓血之灾。

3. 遇七杀星、大、小限重逢，有灾厄或车祸。

4. 大限十年不利，流年一年破财。

★ 丁天干

丁干丁天干令巨门化忌，巨门星是口舌之星，一旦化忌，难免会因言语失当，或是讲话太直率而得罪人。

而且巨门星是一颗相当冷静观察力细腻的星曜，一旦化忌就难免失之于过于计较又严肃，缺乏幽默感，无法谈笑自如且有些自卑感，不然就是会掩饰真象而言过其实，加上疑心病重，所以很难付出真感情，也不容易有浪漫的感情际遇。

★ 丁干生人

1. 不主偏财，主专业技能，学术研究。

2. 天同福星化权：无法清闲，较劳碌，做事有责任。

3. 男命：异性缘佳（太阴化禄）。女命：无法清闲。

4. 巨门化忌：易犯小人、是非及无形干扰。防钱财不露白。

5. 丁干生人、巨门星在疾厄宫：注意胃肠病及无形病。

6. 在子女宫：花柳病，女性子宫不好，下体不好。暗病，巨门为暗水沟。

★ 丁干四化

✪ 太阴化禄

1. 主发财，男命有女孩缘，得异性财，受女性荫。

2. 女命主温柔贤慧，擅理家务，适合经营化妆品、女装、美容院，店面生意佳。

3. 田宅兴旺，置不动产致富赚钱。

4. 大限十年财帛丰足，流年一年财禄风光。

✪ 天同化权

1. 福星化权，职位步步高升，当主管、主任以上之阶级，并有创业、开创新局面之能力。

2. 适合服务业、餐饮业、服饰业。专业技能。

3. 大限份安乐，流年一年平顺。

✪ 天机化科

1. 男女十年福吉祥。适合机械、电工技术、工程。受人欢迎，名声远播。

2. 大限易实现定进财，流年一年平顺。

✪ 巨门化忌

1. 是非十年稳言语上易得罪人。不可接近阴庙，易犯身体不佳，口角不顺。

2. 田宅运途不化忌易遭窃盗。

3. 辰戌宫巨门巨门化忌，财易被骗。

4. 疾厄丑未宫化忌，易得不好医之暗病或癌症，应多修心养性、宫巨门方可解厄，逢凶化吉。

5. 男命布施，反对，受冷落。女命被视为长舌妇，遭到往来主遭人拒绝。

6. 大限户之限波跌起，流年一年不顺。

7. 贪狼桃花星化禄：十年风财或艺术财、从医、也可考虑专业技能。

★ 戊天干

戊干戊天干令天机化忌，天机星是一颗代表聪明智慧的星曜，十分精于计算，非常敏锐，富于观察力。

但若是天机星化忌时，所有的优点也可能成为缺点，其人会过于杞人忧天，多思多虑容易神经质，还会专往坏处着想，变得多愁善感。

当遭遇重大的感情打击时，如不是精神崩溃住进疗养院，就很可能有自残或自虐的行为，甚至会挟怨报复，玩弄感情，绞尽脑汁来折磨或修理负心的人。

因为天机星虽然是善荫，但当它化忌时可是会有很多负面的思维。

★ 戊干生人

1. 主人缘：收受红包。

2. 太阴化权：不动产或土地买卖。

3. 天机化忌：注意思想不开朗，易钻牛角尖（参考何宫），注意四肢手足问题。

★ 戊干四化

✪ 贪狼化禄

1. 人缘极好，适合经商，或往艺术方面进财。并对五术、仙术有极端的爱好。

2. 男命主擅饮花酒，风流雅趣，往娱乐界发展可成名。女命主美容方面、服饰设计。

3. 大限十年暴发，流年一年富有。

✪ 太阴化权

1. 富星化权，能掌财政大权。

2. 女命擅于处理家庭帐务，井井有条，能力强，志气高，凡事自己来，多主劳禄。

3. 大限十年兴旺，流年一年吉利。

✪ 右弼化科

1. 名利双收，有上进心，主有贵人相助，大致多为异性贵人，因此容易主风情，发生感情风波。

2. 大限十年利于考场，流年一年吉祥。

✪ 天机化忌

1. 事业多挫折、阻碍，感情也极不顺利。

2. 男命英雄无用武之地。女命对宗教意识特别虔诚，想出家为尼，看破尘间一切。

3. 此星化忌，易有外伤、车祸事件发生，或工厂机械易故障损坏。易感冒，手足之伤，肝癌。

4. 大限十年辛劳不顺，流年一年不顺。

★ 己天干

己干己天干令文曲化忌，文曲星是一颗才艺星，思维细腻而敏锐，它也是一颗桃花星，属于精神层次的，聪明又富于才情的文曲星。

一旦化忌时，在感情上会有失衡和不安定感，容易遇人不淑，或是爱上不该爱的人，产生迷惘的暧眛之情无法自拔，不仅有可能介入别人的感情成为第三者，自己也可能成为劈腿族的受害者。

且文曲化忌的人也容易对于某些事务或嗜好产生迷恋，执迷不误的态度让另一半无法忍受而导致婚姻、感情破裂。

★ 己干生人

1. 主偏财，生意人，禄权在内局，能者多劳，偏重财运。

2. 需参考禄、权、科、忌在内局或外局，内局佳，外局不佳，内局别人荫我，外局我荫别人。

3. 不从商，属主管阶级，但要参考四化在何宫！是否有禄权组合。

4. 文曲化忌：注意支票、文书、罚单，内局好，外局为欠债，忌不佳。

5. 在何宫，主口角是非，与嘴巴有关，主耗星，易犯小人。

★ 己干四化

✪ 武曲化禄

1. 主财旺，正财收入，也主偏财运，有意外之财获得。

2. 在财帛宫，当为大富翁，女命也主嫁富商成为富婆。

3. 大限十年发财，流年一年财气旺盛。

✪ 贪狼化权

1. 个性暴躁，易得罪人，但其能力强，有成功之一面。适合创作、才艺、餐饮业、娱乐业上成大功立大业。

2. 此星忌与陀罗同度（陀金克木），有灾祸。

3. 喜会武曲或火铃诸星可望成功，但在发财之后，易再损失，宜勇于急退，固守为上策。

4. 大限十年，财名顺遂，流年一年成就发达。

✪ 天梁化科

1. 荫星化科，可得长辈提拔而升官，位居高官，掌大权，也时常因贵人出现帮助而成功。

2. 对士人考试顺利，竞选也能获得大多数人爱戴而当选。适合宗教界、五术界发展，稳定中进财。

3. 大限十年，官场得意，流年一年，主贵人相助而获利。

✪ 文曲化忌

1. 文华之星化忌，不利求学，易遭阻碍，利于研究，不利于考试登科。

2. 对金钱方面要特别小心，注意支票、股票、自助会，不可背书担保。交通易被开罚单。

3. 大限十年阻滞，流年一年不顺失财。

★ 庚天干

庚干庚天干令天同化忌，天同星是一颗福星，福星化忌，自然福份少了许多，人生也比较辛苦，而天同也是一颗情绪星，一旦化忌便容易多愁善感，产生许多负面的情绪。

天同星多情而且又会滥用同情心，加上又耐性不足，在感情上往往难以自我节制，福星化忌在生活的享受也比较缺乏，容易消沉自怨自艾。

天同是多情之星，天同化忌为了爱情可以不要面包，不仅易流于滥情，也常常在情场中识人不明，最后落得人财两失，遭到被抛弃的命运。

★ 庚干生人

1. 太阳化禄：做生意人或服务业。上班不长久（因太阳化禄，很想冲），内局加强。

2. 武曲化权：重赚钱，正、偏财都有，参考内、外局。

3. 天同化忌：无法清闲，劳碌，责任重，做事有责任。男女一样论（然后看忌星在何宫。如夫妻，则解释夫妻对待不佳）。

4. 庚干在夫妻宫，婚姻对待不佳。庚干：先天注意血光、开刀（例：子女宫生产开刀；疾厄宫本身及父母；迁移宫出外注意交通灾厄逢血光）看落何宫而论，例如来因庚干在田宅，属本人及将来生产子女时有血光（因对宫为子女宫），而且庚干化科在疾厄冲父母，父母定有开刀相出现。

★ 庚干四化

✪ 太阳化禄

1. 贵星化禄在财帛或官禄，双美，富贵双全；若在卯辰巳宫，当能掌大权当大官。

2. 落陷宜在忙碌中求财。

3. 女命有人缘，能得异性之帮助而获利。

4. 大限十年吉祥如意，流年一年事业顺畅发达。

✪ 武曲化权

1. 掌财权，甚会理财，不存死钱，若与文曲合为文武双全，声望更高，财帛更丰。

2. 女命有孤克之嫌，主观强，不服输，事业心过重；对丈夫易有忽略感，以致婚姻不和谐而破劣，宜晚婚。

3. 大限十年财广进，权势威武，流年一年通顺。

✪ 太阴化科

1. 有名声，科甲显达；艺术、五术得名，家运也好。

2. 庚干太阴化科用庚金化科，主血光、开刀。

3. 癸干太阴化科则主桃花是所不同。
