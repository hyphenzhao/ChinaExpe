# 本地知识库

将此目录用于存放命理原文资料，系统会在对话时自动检索并引用。

仓库现已包含紫微麦存档的 1,897 篇 `.txt` 和四部典籍的 454 个 Markdown 切片，
约 48 MB（未压缩）。完整典籍见 `data/classics/`。已有文本按本地原件收录，未重新校订；
部分网站抓取文本存在编码乱码，不应把乱码内容直接当作典籍引用。

HTML 网页镜像、`index.json` 倒排索引、`data/lancedb/` 向量库不随 Git 上传。
克隆后可在「设置 → 知识库」重建文本索引；向量检索可运行 `python scripts/build_vectors.py`，
需要可用的 Ollama `bge-m3`。个人学习笔记及其切片继续留在本地。

## 支持的文件格式

- `.txt` — 纯文本
- `.md` — Markdown

## 如何添加内容

### 方式一：从紫微麦复制文章

1. 在紫微麦网站（ziwei.my）上打开目标文章
2. 复制全文
3. 在本目录对应主题下创建 `.txt` 文件，粘贴内容

### 方式二：批量导入

如果已有下载好的紫微麦文章（如爬虫抓取的 `.txt` 文件），直接复制整个目录树到此处。

## 文件命名建议

建议使用有意义的文件名，因为系统会通过文件名和内容进行关键词匹配：

✅ 好：`武曲化科在十二宫位的解释.txt`
❌ 差：`article123.txt`

## 检索原理

系统使用本地倒排索引，从用户问题中提取关键词（如"武曲""化科""迁移宫"），
查找原文片段；配置好向量库与嵌入模型后，还可以结合向量检索。完整典籍支持按行阅读。
