# 本地知识库

将此目录用于存放命理原文资料，系统会在对话时自动检索并引用。

## 目录结构

按主题分目录存放 `.txt` 或 `.md` 文件：

```
knowledge_base/
├── README.md
├── 紫微斗数/
│   ├── 武曲星/
│   │   ├── 甲干武曲化科在十二宫位的解释.txt
│   │   ├── 武曲天府在子午守命宫.txt
│   │   └── ...
│   ├── 迁移宫/
│   │   ├── 迁移宫无主星.txt
│   │   └── ...
│   ├── 四化/
│   │   └── ...
│   └── ...
└── 八字/
    ├── 十神/
    └── ...
```

## 支持的文件格式

- `.txt` — 纯文本
- `.md` — Markdown

## 如何添加内容

### 方式一：从紫微麦复制文章

1. 在紫微麦网站（ziwei.my）上打开目标文章
2. 复制全文
3. 在本目录对应主题下创建 `.txt` 文件，粘贴内容

### 方式二：批量导入

如果已有下载好的紫微麦文章（如爬虫抓取的 `.txt` 文件），直接复制整个目录树到此处。

## 文件命名建议

建议使用有意义的文件名，因为系统会通过文件名和内容进行关键词匹配：

✅ 好：`武曲化科在十二宫位的解释.txt`
❌ 差：`article123.txt`

## 检索原理

系统使用关键词匹配（非向量检索），从用户问题中提取关键词（如"武曲""化科""迁移宫"），
在本地知识库中查找包含这些关键词的文件，将最匹配的原文片段注入到系统提示中。
