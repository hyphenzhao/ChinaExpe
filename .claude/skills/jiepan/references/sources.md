## 检索配方

```bash
# 在所有典籍里找一个术语，带行号
rg -n "自化忌" data/classics/

# 只在飞星派里找，看上下文
rg -n -C 3 "化忌入" "data/classics/02-紫微-四化飞星派/梁若瑜飞星问答.md"

# 找某颗星在某宫的说法
rg -n "太阴.{0,12}疾厄" data/classics/ knowledge_base/

# 现代解释（紫微麦存档按栏目分目录）
rg -n -l "父母宫.*化忌" knowledge_base/si-hua/ knowledge_base/palace-parents/

# 某篇原文太长时，先用篇名定位，再按行号区间读
rg -n "^## " "data/classics/03-子平/子平真诠评注.md" | head -60
```

命中之后，引用格式写成：书名《篇名》，文件路径加行号。例如
`《子平真诠评注·论用神》 data/classics/03-子平/子平真诠评注.md:812`。

## 引用纪律

- 原文照抄，不改字、不补字、不润色成白话后仍称原文。
- 白话解释另起一行，标明"白话"。
- 同一条在不同书里说法冲突时，两条都引，注明书名，让冲突可见。
- 检索不到就写"本机典籍未见此说"，并说明你用的是推理还是现代资料。
