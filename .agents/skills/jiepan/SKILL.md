# 解盘工作法

盘面由排盘引擎算好并导出，你只读不算。典籍在本机，引用必须能被翻到原文。

## 一、铁律

1. **不排盘**。不推算干支、不安星、不起大运、不算真太阳时。一切盘面事实只能来自 `data/exports/<pid>.json`，或本机接口。你若发现盘面可疑，报告疑点，不要自行改算。
2. **引用必须可核对**。凡写"典籍说"，必须给出文件路径与篇名，最好给行号。翻不到就写"未找到出处"，绝不把自己的推演写成古文腔当原文。
3. **断语与推论分开**。典籍原文支持的写在"依据"，你自己的推理写在"推论"，两者不许混写。
4. **先说口径**。每次解盘开头写明用哪一派：三合看星曜庙旺与三方四正，飞星看宫干飞化，四化派看生年四化、自化与来因宫，子平看格局用神与调候。同一问题多派结论不同时并列给出，不要调和成一句。
5. **凶象转成风险与课题**，给可验证的时间点，不做恐吓与绝对化表述。

## 二、盘面从哪里来

```
data/exports/index.json      所有人物一览：id、姓名、性别、出生、农历、五行局
data/exports/<pid>.json      单人完整盘（见下）
data/exports/<pid>.md        同一张盘的文字版，读起来快，适合先看
```

`<pid>.json` 的结构：

| 键 | 内容 |
|---|---|
| `person` | 出生资料、设置、备注 |
| `ziwei` | 十二宫、星曜、亮度、生年四化、自化、身宫、来因宫、大限、`fly` 十二宫宫干飞化 |
| `ziwei_horoscope_now` | 导出时刻的大限/流年/流月/流日/流时各级四化与流曜 |
| `ziwei_yearly_list` | 当前大限的十个流年 |
| `ziwei_monthly_list` | 当年的流月 |
| `bazi` | 四柱、干神、藏干、支神、纳音、空亡、地势、自坐、神煞、干支关系、五行旺衰 |
| `bazi_timeline_now` | 大运序列与当前大运/流年/流月/流日 |
| `text` | 上述内容的中文文字版 |

字段标记：`birth_hua` 生年四化，`self_hua_out` 离心自化（本宫宫干化本宫星），`self_hua_in` 向心自化（对宫宫干化入本宫）。

**换日期时**：JSON 里的运限是导出时刻的。要看别的日期，调本机接口，不要自己推：

```bash
curl -s "http://192.168.50.6:1248/api/people/<pid>/ziwei/horoscope?date=2027-03-05"
curl -s "http://192.168.50.6:1248/api/people/<pid>/bazi/timeline?date=2027-03-05"
curl -s "http://192.168.50.6:1248/api/people/<pid>/ziwei/fly?palace=7"
curl -s -X POST "http://192.168.50.6:1248/api/people/<pid>/export"   # 重新导出为今天
```

Windows 下用 `Invoke-RestMethod`。接口不通就说不通，不要改用心算。

## 三、典籍在哪里

完整原文在 `data/classics/`，检索用的切片在 `knowledge_base/`，两者同源。目录与检索配方见 `references/sources.md`。

先在 `data/classics/` 里用 `rg` 直接找原文，命中后读上下文；需要现代白话解释再去 `knowledge_base/` 的紫微麦存档。

## 四、解盘流程

1. **取盘**：读 `data/exports/<pid>.md` 建立整体印象，需要精确字段时再读 `<pid>.json`。
2. **定题**：把问题落到具体宫位、星曜、干支、时间段，写清楚要回答什么。
3. **找依据**：在 `data/classics/` 检索相关条文，摘出原文，记下文件与篇名。三合与四化两条线分别找。
4. **推演**：结合盘面事实与原文，写出推论链，每一步说明依据来自哪一条。
5. **落地**：给出可验证的时间点与观察指标。
6. **存档**：按 `references/output-template.md` 写入 `data/readings/<pid>/<日期>-<主题>.md`，并把可验证的预测追加到 `data/readings/<pid>/verify.md`。

## 五、盘面口径速查

- 四化表用《紫微斗数全书》口径，与文墨天机默认一致。甲廉破武阳，乙机梁紫阴，丙同机昌廉，丁阴同机巨，戊贪阴右机，己武贪梁曲，庚阳武阴同，辛巨阳曲昌，壬梁紫左武，癸破巨阴贪。顺序为禄权科忌。
- 宫干由五虎遁从年干起，寅宫为首。生年四化即来因宫宫干的四化。
- 分年以正月初一为界，不用立春。时辰用真太阳时，截到分。
- 八字按测测口径，大运用第二种起运法，神煞规则见 `app/engine/bazi/shensha.py`。

## 六、不要做的事

- 不改 `data/exports/` 和 `data/people/` 里的任何文件，那是排盘系统的产物。
- 不把网络上的说法当典籍引用，本机没有就说没有。
- 不为了给结论而把多派口径混成一锅。
- 不在一次回答里堆十几条断语，宁可少而有据。
