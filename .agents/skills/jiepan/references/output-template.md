# 解盘输出模板

回答用户时按这个结构；存档时把同样内容写入
`data/readings/<pid>/<YYYY-MM-DD>-<主题>.md`。

```markdown
# <姓名> · <主题> · <日期>

## 口径
用哪一派，为什么选它。若并列多派，说明各自看什么。

## 盘面事实
只写 JSON 里有的东西，每条注明来自哪一层：本命 / 大限 / 流年 / 流月 / 流日。
例：父母宫[甲戌] 太阴[旺] 生年忌、向心权；流年丙午 廉贞化忌入福德（本命廉贞化禄同宫）。

## 依据
逐条列原文。格式：
- 《书名·篇名》「原文……」 —— 路径:行号
  白话：……

## 断语
典籍原文直接支持的结论，每条后面标注依据编号。

## 推论
你自己的推理，明确写"这是推论"，说明链条与前提。

## 可验证的时间点
给具体年月与可观察的事象，便于日后回填验证。

## 存疑
盘面与典籍冲突处、找不到出处的地方、需要用户补充的事实。
```

验证台账 `data/readings/<pid>/verify.md` 每行一条：

```markdown
- [ ] 2027-03 | 大限乙亥 流年丁未 | 预测：工作变动压力显现 | 依据：《飞星问答》xxx | 结果：
```

日后用户反馈事实时，回填结果并注明命中、部分命中或落空，不要删除原记录。
